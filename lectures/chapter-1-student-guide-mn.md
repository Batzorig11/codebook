# Бүлэг 1: Python програмчлалын эхлэл

Энэ гарын авлага нь Chapter 1-ийн түвшнүүдийг хийхдээ ойлгох ёстой гол санаа, ашиглах команд, өөрийгөө шалгах асуултуудыг нэг дор цуглуулсан материал юм.

## Энэ бүлгээр юу сурах вэ?

Chapter 1 дээр  Python код биж тоглоомын дүрийг хөдөлгөнө. Кодоо Code Editor дээр бичээд `Run` товч дарснаар дүр нь командуудыг дээрээс доошоо дарааллаар гүйцэтгэнэ.

Энэ бүлгийн төгсгөлд  дараах зүйлсийг хийж чаддаг болно:

- Code Editor дээр Python команд бих
- `Run` товч дарж кодоо ажиллуулах
- `player` модулийн функцуудыг ашиглах
- Дүрийг урагшлуулах, зүүн/баруун тийш эргүүлэх
- Функцэд аргумент дамжуулж олон алхам хийх
- Саад түлхэх, дэлгэц дээр үг хэлүүлэх, гүүр барих
- Командын дарааллыг төлөвлөж богино шийдэл бих

## Код гэж юу вэ?

Код бол компьютерт өгч байгаа заавар юм. Тоглоомын дүр өөрөө шийдвэр гаргахгүй. ний бичсэн командын дагуу л хөдөлнө.

Жишээ:

```python
player.move_forward()
```

Энэ команд дүрийг нэг алхам урагшлуулна.

## Функц гэж юу вэ?

Функц гэдэг нь тодорхой үйлдэл хийдэг команд юм. Chapter 1 дээр бид ихэвчлэн `player` модулийн функцуудыг ашиглана.

Функц дуудах ерөнхий хэлбэр:

```python
player.function_name()
```

Жишээ:

```python
player.turn_left()
player.turn_right()
```

Эдгээр командууд дүрийг зүүн эсвэл баруун тийш эргүүлнэ.

## Командын дараалал

Python код дээрээс доошоо мөр мөрөөрөө ажилладаг. Тиймээс аль командыг түрүүлж бих нь маш чухал.

```python
player.move_forward()
player.turn_right()
player.move_forward()
```

Энэ код дараах дарааллаар ажиллана:

1. Нэг алхам урагш явна.
2. Баруун тийш эргэнэ.
3. Дахин нэг алхам урагш явна.

Хэрэв мөрүүдийн дарааллыг өөрлбөл дүр өөр замаар явна.

## Аргумент гэж юу вэ?

Аргумент гэдэг нь функцэд дамжуулж буй утга юм. Жишээ нь `move_forward()` функцэд алхмын тоо өгч болно.

```python
player.move_forward(3)
```

Энэ команд дүрийг гурван алхам урагшлуулна. Энд байгаа `3` бол аргумент.

## Chapter 1-д ашиглах командууд

| Команд | Юу хийдэг вэ? |
| --- | --- |
| `player.move_forward()` | Дүрийг нэг алхам урагшлуулна. |
| `player.move_forward(3)` | Дүрийг гурван алхам урагшлуулна. |
| `player.turn_left()` | Дүрийг зүүн тийш эргүүлнэ. |
| `player.turn_right()` | Дүрийг баруун тийш эргүүлнэ. |
| `player.push()` | Дүрийн өмнөх чулууг түлхэнэ. |
| `player.speak('Hello')` | Дэлгэц дээр `Hello` гэж хэлүүлнэ. |
| `player.build('bridge')` | Цуглуулсан модоор гүүр барина. |

## Түвшин бүрийн тайлбар

### Level 1: Starting Out

Энэ түвшинд  анхны Python командаа бичнэ.

Ашиглах команд:

```python
player.move_forward()
```

Анхаарах зүйл:

- Командын төгсгөлд `()` хаалт заавал байна.
- Кодоо бичээд `Run` товч дарна.
- Нэг мөр код нэг тодорхой үйлдэл хийж байгааг ажигла.

### Level 2: Movement with Functions

Энэ түвшинд  дүрийг ой дундуур явуулж гарц руу хүргэнэ.

Ашиглах командууд:

```python
player.move_forward()
player.turn_left()
player.turn_right()
```

Эхлээд газрын зургаа ажигла:

- Дүр аль зүг рүү харж байна вэ?
- Од эсвэл гарц хаана байна вэ?
- Эхлээд урагшлах уу, эсвэл эргэх үү?

Код бихээс өмнө замаа богиноор төлөвлөх нь алдаа багасгана.

### Level 3: Collecting Items

Энэ түвшинд  газрын зураг дээрх жимснүүдийг цуглуулна.

Шинэ санаа: нэг командыг олон удаа бихийн оронд аргумент ашиглаж болно.

```python
player.move_forward(3)
```

Энэ нь дараахтай ижил утгатай:

```python
player.move_forward()
player.move_forward()
player.move_forward()
```

Аргумент ашиглавал код богино, уншихад ойлгомжтой болно.

### Level 4: Pushing Objects

Энэ түвшинд замыг чулуу хаана. Чулууг түлхэхийн тулд `push()` функцийг ашиглана.

```python
player.push()
```

Анхаарах зүйл:

- Дүр чулуу руу харсан байх ёстой.
- Эхлээд зөв байрлалд очоод, зөв глэл рүү харж байгаагаа шалга.
- Дараа нь `player.push()` гэж бич.

### Level 5: Printing on Screen

Энэ түвшинд  X тэмдэг дээр очоод `Hello` гэж хэлүүлнэ.

```python
player.speak('Hello')
```

`Hello` нь текст учраас хашилтын дотор бигдэнэ.

Зөв:

```python
player.speak('Hello')
```

Буруу:

```python
player.speak(Hello)
```

### Level 6: Building Objects

Энэ түвшинд  мод цуглуулж гүүр барина.

```python
player.build('bridge')
```

Анхаарах зүйл:

- Модны дээгүүр алхвал мод цугларна.
- Гүүр барихын өмнө шаардлагатай модоо цуглуулсан байх хэрэгтэй.
- `bridge` гэдэг үгийг яг зөв бичнэ.
- `bridge` нь текст тул хашилтын дотор бигдэнэ.

### Level 7: Apply What You've Learned

Энэ түвшин өмнөх бүх ойлголтыг нэгтгэнэ.

 дараах зүйлсийг хамтад нь ашиглана:

- Урагшлах
- Эргэх
- Чулуу түлхэх
- Мод цуглуулах
- Гүүр барих
- Зөв дараалал төлөвлөх

Код бихээс өмнө өөрөөсөө асуу:

1. Эхлээд хаашаа явах вэ?
2. Замд чулуу байна уу?
3. Гүүр барихын өмнө мод цуглуулах хэрэгтэй юу?
4. Аль командуудыг ямар дарааллаар бих вэ?

## Алдаа гарвал яах вэ?

Алдаа гарвал шууд бүх кодоо устгах хэрэггүй. Дараах дарааллаар шалга:

1. Командын нэр зөв бигдсэн үү?
2. `()` хаалт байгаа юу?
3. Текстийг `' '` хашилтын дотор бичсэн үү?
4. Дүр зөв глэл рүү харж байна уу?
5. Командууд зөв дарааллаар бигдсэн үү?
6. `Run` дарсны дараа дүр яг аль мөр дээр буруу хөдөлж эхэлж байна вэ?

## Дасгал

Дараах жижиг даалгавруудыг өөрөө туршаарай.

1. Дүрийг гурван алхам урагшлуулах хоёр өөр код бич.
2. Дүрийг нэг алхам урагшлуулаад баруун тийш эргүүлж, дахин нэг алхам явуулах код бич.
3. `player.speak('Hello')` командын `Hello` үгийг өөр үгээр сольж турш.
4. `player.move_forward(5)` гэж бичвэл юу болохыг таамаглаад ажиллуулж шалга.

Код бихдээ эхлээд газрын зургаа ажигла, дараа нь замаа төлөвлө, тэгээд командаа бич. Алдаа гарвал кодоо мөр мөрөөр нь уншиж, дүр нь яг ямар үйлдэл хийж байгааг шалга.
