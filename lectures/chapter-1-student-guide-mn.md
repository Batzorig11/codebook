# Бүлэг 1: Python програмчлалын эхлэл

> **Энэ хичээлээр:**
> Программ яаж ажилладаг нууцыг онолын талаас нь тайлж, тоглогчоо кодоор хөдөлгөж, дэлгэц дээр мэдээлэл хэвлэж сурна.

# Алхам 1: Код гэж юу вэ? (Дээрээс доош)

Компьютер манай кодыг яг л номын хуудас уншиж байгаа мэт дээрээс нь доош, мөр мөрөөр нь дарааллын дагуу уншиж ажиллуулдаг. Үүнийг програмчлалд **Дараалал (Sequence)** гэж нэрлэдэг бөгөөд энэ нь алгоритмын хамгийн анхны суурь бүтэц юм.

```python
import player

player.move_forward(4)
player.turn_left()
```

**Python үүнийг яаж ойлгож байгаа вэ?**

- **1-р мөр:** `import player` команд нь өөр хөгжүүлэгчдийн бэлдсэн кодын цуглуулга буюу **Сан (Library)**-г өөрийн програмд урьж авчирна. Ингэснээр тоглогчийг удирдах хэрэгслүүд бэлэн болно.
- **2-р мөр:** Дараа нь тоглогчийг 4 блок урагшлуулах функцийг ажиллуулна.
- **3-р мөр:** Хамгийн сүүлд нь зүүн тийш эргэх функцийг гүйцэтгэнэ.

**Яагаад дараалал чухал вэ?**

Хэрэв чи зүүн эргэх тушаалыг урд нь биччихвэл тоглогч эхлээд эргээд, дараа нь өөр зүг рүү алхчихна. Программ хэзээ ч мөр алгасаж эсвэл доороос нь дээш уншдаггүй.

---

# Алхам 2: Функц гэж юу вэ? (Бэлэн тушаал)

Програмчлалд **Функц (Function)** гэдэг нь тодорхой нэгэн үйлдлийг хийх зориулалттай, дахин ашиглаж болдог кодын багц юм. Чи тэр үйлдлийг заавал шинээр зохиох албагүй, зөвхөн нэрийг нь дуудахад л хангалттай.

```python
player.collect_item()
player.push()
```

**Энэ код яаж ажилласан бэ?**

- `player.collect_item()` — "Газар байгаа зүйлийг цуглуулж уут руугаа ав" гэдэг үүрэгтэй функц.
- `player.push()` — "Урд байгаа хайрцгийг түлх" гэдэг үүрэгтэй функц.

**`()` хаалт яагаад хэрэгтэй вэ?**

Функцийн нэрний ард заавал `()` хаалт тавьдаг. Үүнийг програмчлалд **Функц дуудах (Function Call)** гэх бөгөөд компьютерт "Энэ тушаалыг одоо шууд ажиллуул!" гэж хэлж байгаа дохио юм.

> **Анхаарах:** Хэрэв чи хаалтгүй `player.push` гэж бичвэл компьютер "Энд түлхэх гэдэг функц байна" гэж таних боловч үйлдэл болгож ажиллуулахгүй.

---

# Алхам 3: Аргумент ашиглах (Нэмэлт мэдээлэл)

**Аргумент (Argument)** гэдэг нь функц ажиллахдаа дотроо авч буй нэмэлт мэдээлэл буюу утга юм. Жишээ нь `move_forward()` функцэд алхмын тоог аргумент болгон өгч болно.

```python
player.move_forward(3)
```

Энэ команд дүрийг гурван алхам урагшлуулна. Энд байгаа `3` бол хаалтан дотор дамжуулж буй аргумент юм.

| Команд | Юу хийдэг вэ? | Тайлбар |
| --- | --- | --- |
| `player.move_forward()` | Дүрийг нэг алхам урагшлуулна. | Аргументгүй дуудалт. |
| `player.move_forward(3)` | Дүрийг 3 алхам урагшлуулна. | `3` нь тоон аргумент. |
| `player.turn_left()` | Дүрийг зүүн тийш эргүүлнэ. | Аргументгүй дуудалт. |
| `player.turn_right()` | Дүрийг баруун тийш эргүүлнэ. | Аргументгүй дуудалт. |
| `player.push()` | Дүрийн урд байгаа чулууг түлхэнэ. | Аргументгүй дуудалт. |
| `player.speak('Hello')` | Дэлгэц дээр `Hello` гэж хэлүүлнэ. | `'Hello'` нь текстэн аргумент. |
| `player.build('bridge')` | Цуглуулсан модоор гүүр барина. | `'bridge'` нь текстэн аргумент. |

---

# Алхам 4: Тоглоомын түвшинд хэрэглэх

Энэ алхамд бид өмнөх 3 алхамд сурсан онолын ойлголтоо тоглоомын түвшин бүрт хэрхэн ашиглахыг харъя.

**Level 1: Starting Out**

Энэ түвшинд анхны Python командаа бичиж, функц дуудах онолыг хэрэгжүүлнэ.

```python
player.move_forward()
```

- Функц дуудаж байгаа тул командын төгсгөлд `()` хаалт заавал байна.
- Кодоо бичээд `Run` товч дарж програмаа ажиллуулна.

**Level 2: Movement with Functions**

Энэ түвшинд кодын **Дараалал (Sequence)**-ыг ашиглан дүрийг ой дундуур явуулж гарц руу хүргэнэ.

```python
player.move_forward()
player.turn_left()
player.turn_right()
```

Эхлээд газрын зургаа ажигла:
- Дүр аль зүг рүү харж байна вэ? (Эхлэх цэг)
- Од эсвэл гарц хаана байна вэ? (Зорилтот цэг)

**Level 3: Collecting Items**

Нэг функцийг олон удаа дараалуулан бичихийн оронд аргумент ашиглаж кодоо богиносгоно.

```python
player.move_forward(3)
```

Энэ нь дараах дараалалтай яг ижил үр дүнтэй:

```python
player.move_forward()
player.move_forward()
player.move_forward()
```

Аргумент ашиглавал код илүү богино, уншихад ойлгомжтой буюу цэгцтэй болдог.

**Level 4: Pushing Objects**

Замыг чулуу хаасан үед чулууг түлхэхийн тулд `push()` функцийг дуудна.

```python
player.push()
```

- Дүр заавал чулуу руу харсан байх ёстой.
- Дарааллын дагуу эхлээд зөв байрлалд очоод, зөв чиглэл рүү харж байгаагаа шалгаарай.

**Level 5: Printing on Screen**

X тэмдэг дээр очоод `Hello` гэж хэлүүлнэ. Програмчлалд дэлгэц дээр мэдээлэл гаргахыг **Хэвлэх (Print)** гэж нэрлэдэг. Python-д үүнийг үндсэн `print()` функцээр хийдэг бол манай тоглоомд `player.speak()` функцээр гүйцэтгэнэ.

```python
player.speak('Hello')
```

`Hello` бол **Текстэн өгөгдөл (String)** учраас заавал `' '` хашилтын дотор бичигдэнэ.

> **Анхаарах:** `player.speak(Hello)` гэж бичвэл алдаа гарна. Хашилтгүй үгийг компьютер код эсвэл хувьсагч гэж андуурдаг тул текст үгс үргэлж хашилтанд байх ёстой.

**Level 6: Building Objects**

Мод цуглуулж гүүр барина.

```python
player.build('bridge')
```

- Модны дээгүүр алхвал дүр модыг автоматаар цуглуулна.
- `bridge` гэдэг нь текстэн өгөгдөл тул мөн адил хашилтанд бичигдэнэ.

**Level 7: Apply What You've Learned**

Энэ түвшин өмнөх бүх онолын ойлголтуудыг нэгтгэнэ.

- **Дарааллыг** зөв тооцоолох
- **Функцүүдийг** зөв дуудах
- **Тоон** болон **Текстэн** аргументуудыг зөв ашиглах

Код бичихээс өмнө алгоритмаа ингэж төлөвлөөрэй:
1. Эхлээд хаашаа, хэдэн алхам явах вэ?
2. Замд чулуу байна уу, түүнийг түлхэх үү?
3. Гүүр барихаас өмнө мод цуглуулах дараалал зөв үү?

# Алхам 5: Нийтлэг алдаа (Анхаарах зүйлс)

Кодонд алдаа (**Bug**) гарвал шууд устгах хэрэггүй. Алдааг олж засахыг **Debugging** гэдэг. Эхлээд доорх хүснэгтээс шалгаарай.

| Алдаа | Яагаад буруу вэ? (Онолын шалтгаан) | Зөв хэлбэр |
| --- | --- | --- |
| `player.move_forward` | Функц дуудах `()` хаалт дутуу байна. | `player.move_forward()` |

**Алдаа гарвал шалгах дараалал:**

**Зөв хариулт:** Б

# Дүгнэлт

Энэ бүлэгт үзсэн програмчлалын суурь онолуудыг үргэлж санаж яваарай:

- **Дараалал (Sequence):** Компьютер кодыг хэзээ ч алгасахгүй, үргэлж дээрээс доош мөр мөрөөр уншдаг.
- **Сан (Library):** import ашиглан бусдын бэлдсэн бэлэн кодыг програмдаа оруулж ирдэг.
- **Функц дуудах (Function Call):** Функцийн нэрний ард () хаалт тавьж байж тушаал ажиллагаанд орно.
- **Аргумент (Argument):** Функцийн хаалтан дотор өгч буй нэмэлт мэдээлэл. Тоог шууд, текстийг заавал `' '` хашилтанд бичнэ.

---

# Гол санаа

- Код дээрээс доош дарааллаар ажилладаг (**Sequence**)
- import = бусдын бэлдсэн **Санг (Library)** оруулж ирнэ
- () хаалт = функцийг дуудаж ажиллуулах (**Function Call**)
- Аргумент = функцийн хаалтан доторх нэмэлт мэдээлэл
- Текстийг ' ' хашилтад бичдэг (**String**)
