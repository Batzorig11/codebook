# Бүлэг 1: Python програмчлалын эхлэл

## Хичээлийн сэдэв
**Python кодоор тоглоомын дүрийг хэрхэн хөдөлгөх вэ?**

## Зорилго
Энэ хичээлийн дараа сурагчид:

- Code Editor дээр Python команд бичнэ
- `Run` товч дарж кодоо ажиллуулна
- `player` модулийн функцуудыг ашиглана
- Дүрийг урагшлуулах, зүүн болон баруун тийш эргүүлэх команд бичнэ
- Function-д argument дамжуулж олон алхам хийлгэнэ
- Саад түлхэх, дэлгэц дээр үг хэлүүлэх, гүүр барих командуудыг хэрэглэнэ
- Командын дарааллыг төлөвлөж богино шийдэл бичнэ

---

## 1. Код гэж юу вэ?

Код бол компьютерт өгч байгаа заавар юм.

Тоглоомын дүр өөрөө шийдвэр гаргахгүй. Таны бичсэн командын дагуу дээрээс доошоо дарааллаар хөдөлнө.

Жишээ:

```python
player.move_forward()
```

Энэ команд дүрийг нэг алхам урагшлуулна.

---

## 2. Python код хэрхэн ажилладаг вэ?

Python код мөр мөрөөрөө дээрээс доошоо ажилладаг.

```python
player.move_forward()
player.turn_right()
player.move_forward()
```

Энэ код дараах дарааллаар ажиллана:

1. Нэг алхам урагш явна
2. Баруун тийш эргэнэ
3. Дахин нэг алхам урагш явна

Хэрэв мөрүүдийн дарааллыг өөрчилбөл дүр өөр замаар явна.

---

## 3. Function гэж юу вэ?

**Function** гэдэг нь тодорхой үйлдэл хийдэг команд юм.

Chapter 1 дээр бид ихэвчлэн `player` модулийн функцуудыг ашиглана.

Функц дуудах ерөнхий хэлбэр:

```python
player.function_name()
```

Жишээ:

```python
player.turn_left()
player.turn_right()
```

Эдгээр командууд дүрийг зүүн эсвэл баруун тийш эргүүлнэ.

---

## 4. Дүрийг хөдөлгөх үндсэн командууд

Дүрийг хөдөлгөхөд дараах командууд хамгийн их ашиглагдана.

```python
player.move_forward()
player.turn_left()
player.turn_right()
```

Анхаарах зүйлс:

- Командын нэрийг яг зөв бичнэ
- Function нэрний дараа `()` хаалт заавал байна
- Нэг мөр код нэг тодорхой үйлдэл хийдэг
- Кодоо бичээд `Run` товч дарж шалгана

---

## 5. Argument гэж юу вэ?

**Argument** гэдэг нь function-д дамжуулж буй утга юм.

Жишээ:

```python
player.move_forward(3)
```

Энэ команд дүрийг гурван алхам урагшлуулна.

Дээрх код нь дараахтай ижил утгатай:

```python
player.move_forward()
player.move_forward()
player.move_forward()
```

Argument ашиглавал код богино, уншихад ойлгомжтой болно.

---

## 6. Саад түлхэх, ярих, гүүр барих

Тоглоомын түвшинд зөвхөн алхах биш, өөр үйлдлүүд бас хэрэгтэй.

```python
player.push()
player.speak("Hello")
player.build("bridge")
```

Эдгээр командын утга:

- `player.push()` нь дүрийн өмнөх чулууг түлхэнэ
- `player.speak("Hello")` нь дэлгэц дээр үг хэлүүлнэ
- `player.build("bridge")` нь цуглуулсан модоор гүүр барина

Текст утгыг заавал хашилтын дотор бичнэ.

---

## 7. Game-based coding жишээ

Доорх жишээ нь дүрийг урагш явуулаад баруун тийш эргүүлж байна.

```python
import player

player.move_forward()
player.turn_right()
player.move_forward(2)
player.speak("Done")
```

## 8. Түвшин бүрийн тайлбар

### Level 1: Starting Out

Зорилго: Анхны Python командаа бичиж дүрийг хөдөлгө.

Гол санаа: `player.move_forward()` команд нэг алхам урагшлуулна.

### Level 2: Movement with Functions

Зорилго: Дүрийг ой дундуур явуулж гарц руу хүргэ.

Гол санаа: `move_forward()`, `turn_left()`, `turn_right()` командуудыг зөв дарааллаар ашиглана.

### Level 3: Collecting Items

Зорилго: Газрын зураг дээрх жимснүүдийг цуглуул.

Гол санаа: Нэг командыг олон удаа бичихийн оронд `player.move_forward(3)` хэлбэрээр argument ашиглаж болно.

### Level 4: Pushing Objects

Зорилго: Зам хаасан чулууг түлхэж гарц руу хүр.

Гол санаа: Дүр чулуу руу харсан үед `player.push()` команд ажиллана.

### Level 5: Printing on Screen

Зорилго: `X` тэмдэг дээр очоод `Hello` гэж хэлүүл.

Гол санаа: `player.speak("Hello")` доторх `Hello` нь текст тул хашилттай бичигдэнэ.

### Level 6: Building Objects

Зорилго: Мод цуглуулж гүүр барь.

Гол санаа: Мод цуглуулсны дараа `player.build("bridge")` командыг ашиглана.

### Level 7: Apply What You've Learned

Зорилго: Өмнөх бүх ойлголтыг нэгтгэн түвшнийг дуусга.

Гол санаа: Урагшлах, эргэх, түлхэх, мод цуглуулах, гүүр барих үйлдлүүдийг зөв дарааллаар төлөвлөнө.
