# Бүлэг 3: Үндсэн операторууд

## Хичээлийн сэдэв
**Python оператор ашиглан тооцоо болон текст формат хэрхэн хийх вэ?**

## Зорилго
Энэ хичээлийн дараа сурагчид:

- Тоон утгууд дээр `+`, `-`, `*`, `/` оператор ашиглана
- Хувьсагчийн утгыг `-=`, `*=` зэрэг оператороор шинэчилнэ
- Тоон нийлбэр, ялгавар, үржвэрийг `speak()` function-ээр харуулна
- Текст формат ашиглан тоо болон үгийг өгүүлбэрт оруулна
- Тооцоог текстээс ялгаж бичнэ

---

## 1. Оператор гэж юу вэ?

**Оператор** гэдэг нь утгууд дээр тооцоо хийдэг тэмдэг юм.

Жишээ:

```python
cows = 3
goats = 2
total = cows + goats
```

Энд `+` оператор хоёр тоог нэмж байна.

---

## 2. Нэмэх ба хасах

`+` нь тоонуудыг нэмнэ. `-` нь нэг утгаас нөгөө утгыг хасна.

```python
cows = 3
goats = 2
pigs = 4

player.speak(cows + goats + pigs)
```

Гаралт:

```text
9
```

Хасах жишээ:

```python
eggs = 10
broken_eggs = 4
player.speak(eggs - broken_eggs)
```

---

## 3. Утгыг шинэчлэх операторууд

Хувьсагчийн одоогийн утгыг богино хэлбэрээр шинэчилж болно.

```python
white_eggs = 10
white_eggs -= 2

red_eggs = 3
red_eggs *= 2
```

Энэ кодын дараа:

- `white_eggs` нь `8` болно
- `red_eggs` нь `6` болно

---

## 4. Үржүүлэх ба хуваах

`*` нь үржүүлэх, `/` нь хуваах оператор юм.

```python
baskets = 4
eggs_per_basket = 6

total_eggs = baskets * eggs_per_basket
player.speak(total_eggs)
```

Гаралт:

```text
24
```

---

## 5. Текст формат гэж юу вэ?

Текст дотор хувьсагчийн утга оруулахад string format ашиглаж болно.

```python
egg_basket = 12
player.speak("there are %d eggs" % egg_basket)
```

Гаралт:

```text
there are 12 eggs
```

Анхаарах зүйлс:

- `%d` нь тоонд ашиглагдана
- `%s` нь текстэд ашиглагдана
- Тооцоог хашилтын дотор бичвэл Python тооцохгүй, текст гэж үзнэ

---

## 6. Game-based coding жишээ
