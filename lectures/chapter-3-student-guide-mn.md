# Бүлэг 3: Үндсэн операторууд

Энэ бүлэгт Python ашиглан нэмэх, хасах, үржүүлэх, хуваах болон текст форматлах аргыг сурна.

## Энэ бүлгээр юу сурах вэ?

- Тоон утгууд дээр `+`, `-`, `*`, `/` оператор ашиглах
- Хувьсагчийн утгыг `-=`, `*=` зэрэг оператороор шинэчлэх
- Тоон нийлбэр, ялгавар, үржвэрийг `speak()` функцээр харуулах
- Текст формат ашиглан тоо болон үгийг өгүүлбэрт оруулах

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| Оператор | Утгууд дээр тооцоо хийдэг тэмдэг. | cows + goats |
| Нэмэх | Тоонуудыг нийлүүлнэ. | total = cows + goats + pigs |
| Хасах | Нэг утгаас нөгөө утгыг хасна. | eggs - 4 |
| Үржүүлэх | Утгыг хэд дахин өсгөнө. | red_eggs *= 2 |
| String format | Текст дотор хувьсагчийн утга оруулна. | "%d eggs" % eggs |

## Ашиглах команд ба жишээнүүд

| Код | Юу хийдэг вэ? |
| --- | --- |
| player.speak(cows) | Хувьсагчийн утгыг хэлүүлнэ. |
| player.speak(cows + goats + pigs) | Нийлбэрийг тооцоод хэлүүлнэ. |
| white_eggs -= 2 | Цагаан өндөгний тооноос 2-ыг хасна. |
| red_eggs *= 2 | Улаан өндөгний утгыг 2 дахин өсгөнө. |
| player.place(bag1) | Тооцоолсон утгыг байрлуулна. |

## Жишээ код

```python
cows = 3
goats = 2
pigs = 4
player.speak(cows + goats + pigs)
player.speak("there are %d eggs" % egg_basket)
```

### Level 1: Counting with code

Зорилго: Жүчээ бүрт хэдэн амьтан байгааг олж, нийлбэрийг нь тооцоод түвшнийг дуусга!

Гол санаа: Амьтдын тоог хувьсагчид хадгалаад нийлбэрийг `+` оператороор олно.

### Level 2: Add and Subtract

Зорилго: Өндөгнүүдээ цуглуулаад тоонуудыг нь нэмж хасч тооцоогоо хөтөлцгөөе!

Гол санаа: Өндөгний тоог нэмэх, муудсан өндгийг хасах, шаардлагатай бол үржүүлэх дадлага хийнэ.

### Level 3: String Formats

Зорилго: Тахиануудыг дуудаад торгоолон бүрийн эргэн тойрон дахь тахианы тоог тэмдэглэцгээе!

Гол санаа: Текст дотор тоо оруулахын тулд формат ашиглана.

### Level 4: Constants and Practice

Зорилго: Сагс дүүрэн өндгөө авчраад савнуудад хадгалж, хэдэн өндөг байгааг хэлцгээе!

Гол санаа: Тогтмол болон хувьсагчийн утгыг тооцоонд ашиглаж үр дүнг байрлуулж, хэлүүлнэ.

## Нийтлэг алдаа

| Алдаа | Яагаад буруу вэ? | Зөв хэлбэр |
| --- | --- | --- |
| player.speak("cows + goats") | Тооцоо биш текст хэлнэ. | player.speak(cows + goats) |
| white_eggs =- 2 | Операторын дараалал буруу. | white_eggs -= 2 |
| red_eggs =* 2 | Операторын дараалал буруу. | red_eggs *= 2 |
| "%d eggs" % (name) | `%d` нь тоонд зориулагдсан. | "%s" % name |

## Алдаа гарвал шалгах зүйлс

3. Текст утга хашилтын дотор байна уу?
4. Indentation буюу мөрийн зай зөв байна уу?
5. Кодын дараалал газрын зураг дээрх үйлдэлтэй таарч байна уу?
6. `Run` дарсны дараа аль мөрөөс буруу үр дүн гарч байгааг ажигласан уу?
