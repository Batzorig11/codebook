# Алхам 1: Үндсэн операторууд (+, -, *, /)

Оператор гэдэг нь утгууд дээр тооцоо хийдэг тэмдэг юм.

| Оператор | Үйлдэл | Жишээ |
| --- | --- | --- |
| `+` | Нэмэх | `total = cows + goats` |
| `-` | Хасах | `eggs = eggs - 4` |
| `*` | Үржүүлэх | `red_eggs *= 2` |
| `/` | Хуваах | `half = total / 2` |

**Жишээ код:**

```python
cows = 3
goats = 2
pigs = 4

# Нийлбэрийг тооцоод хэлүүл
player.speak(cows + goats + pigs)
```

**Гаралт:**
```
9
```

> **Гол санаа:**
> Тооцоог хашилтын дотор бичиж болохгүй. `player.speak("cows + goats")` гэвэл текст хэлнэ, тооцоо хийхгүй.

# Алхам 2: Хувьсагчийн утгыг шинэчлэх (+=, -=, *=)

Хувьсагчийн утгыг шинэчлэхдээ богино бичигдэл ашиглаж болно.

| Урт бичигдэл | Богино бичигдэл | Үр дүн |
| --- | --- | --- |
| `eggs = eggs - 2` | `eggs -= 2` | Утгаас 2 хасна |
| `eggs = eggs * 2` | `eggs *= 2` | Утгыг 2 дахин өсгөнө |
| `eggs = eggs + 5` | `eggs += 5` | Утгыг 5-аар нэмнэ |

**Жишээ:**

```python
white_eggs = 10
white_eggs -= 4  # Одоо 6 болно

red_eggs = 3
red_eggs *= 2    # Одоо 6 болно
```

> **Анхаарах:**
> `white_eggs =- 2` гэж бичвэл алдаа гарна. Зөв нь `white_eggs -= 2`.

# Алхам 3: Текст форматлах (%d, %s)

Текст дотор тоо болон үгийг оруулахын тулд формат ашиглана.

| Формат | Ямар утга | Жишээ |
| --- | --- | --- |
| `%d` | Тоо | `"%d eggs" % eggs` |
| `%s` | Текст | `"Hello %s" % name` |

**Жишээ:**

```python
apples = 5
player.speak("there are %d apples" % apples)
```

**Гаралт:**
```
there are 5 apples
```

**Текст оруулах:**

```python
name = "Alice"
player.speak("Hello %s" % name)
```

**Гаралт:**
```
Hello Alice
```

> **Анхаарах:**
> `%d` нь тоонд, `%s` нь текстэд зориулагдсан. `%d`-д текст өгвөл алдаа гарна.

# Алхам 4: Тоглоомын түвшинд хэрэглэх

**Level 1: Counting with code**

Амьтдын тоог хувьсагчид хадгалаад нийлбэрийг `+` оператороор олно.

```python

player.speak(cows + goats)
```

Өндөгний тоог нэмэх, муудсан өндгийг хасах.

Торгоолон бүрийн эргэн тойрон дахь тахианы тоог тэмдэглэ.

```python

```

**Level 4: Constants and Practice**

Тогтмол болон хувьсагчийн утгыг тооцоонд ашигла.

```python

```

# Quiz: Өөрийгөө шалгаарай

## Асуулт 1
`+` оператор юу хийдэг вэ?

- А) Хасах
- Б) Нэмэх
- В) Үржүүлэх
- Г) Хуваах

**Зөв хариулт:** Б
**Тайлбар:** `+` оператор нь тоонуудыг нийлүүлдэг. Жишээ: `3 + 2 = 5`.

## Асуулт 2
`-=` оператор ямар үед хэрэгтэй вэ?

- А) Утгыг нэмэхдээ
- Б) Утгыг хасахдаа
- В) Утгыг үржүүлэхдээ
- Г) Утгыг хуваахдаа

**Зөв хариулт:** Б
**Тайлбар:** `-=` нь хувьсагчийн утгаас тоог хасах богино бичигдэл. Жишээ: `eggs -= 2`.

## Асуулт 3
`red_eggs *= 2` дараа утга яаж өөрчлөгдөх вэ?

- А) 2 хасагдана
- Б) 2 дахин өснө
- В) 2 хуваагдана
- Г) Үргэлж 2 болно

**Зөв хариулт:** Б
**Тайлбар:** `*=` нь хувьсагчийн утгыг хэд дахин өсгөдөг. Жишээ: `3 *= 2` бол `6` болно.

## Асуулт 4
`%d` болон `%s` хоёрын ялгаа юу вэ?

- А) Ялгаагүй, хоёул адилхан
- Б) `%d` = тоо, `%s` = текст
- В) `%d` = текст, `%s` = тоо
- Г) `%d` = хуваах, `%s` = нэмэх

**Зөв хариулт:** Б
**Тайлбар:** `%d` нь тоонд (digit), `%s` нь текстэд (string) зориулагдсан формат.

## Асуулт 5
Яагаад тооцоог хашилтын дотор бичиж болохгүй вэ?

- А) Python зөвшөөрдөггүй
- Б) Текст болж хувирна
- В) Алдаа гарна
- Г) Хурдасна

**Зөв хариулт:** Б
**Тайлбар:** Хашилтанд бичсэн бүх зүйл текст болно. `"3 + 2"` гэвэл тооцоо биш текст "3 + 2" гэж харагдана.

## Асуулт 6

# Дүгнэлт

Энэ бүлэгт чи:

1. `+`, `-`, `*`, `/` операторуудыг сурлаа
2. Хувьсагчийн утгыг шинэчлэх богино бичигдлийг (`+=`, `-=`, `*=`) сурлаа
3. Текст форматлах (`%d`, `%s`) аргыг сурлаа
4. Тооцоог хашилтын дотор бичиж болохгүйг ойлголоо
5. Операторуудын дарааллыг зөв бичихыг сурлаа

Операторууд нь хувьсагчийн утгыг тооцоолж, шинэ үр дүн гаргахад ашиглагддаг.

---

# Гол санаа

- `+` = нэмэх, `-` = хасах, `*` = үржүүлэх, `/` = хуваах
- `-=` = хасах, `*=` = үржүүлэх (богино бичигдэл)
- `%d` = тоо форматлах, `%s` = текст форматлах
- Тооцоог хашилтын дотор бичиж болохгүй
- `=+` буруу, `+=` зөв
