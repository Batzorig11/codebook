# Бүлэг 9: Class ба object

Энэ бүлэгт class ашиглан өөрийн төрлийн объект үүсгэх, шинж чанар болон method ашиглах үндсийг сурна.

## Энэ бүлгээр юу сурах вэ?

- Class гэж юу болохыг ойлгох
- Class-аас object үүсгэх
- Object-ийн шинж чанар буюу member хадгалах
- `__init__()` ашиглан object эхлүүлэх
- Class method тодорхойлж дуудах
- Object-ийг функцэд дамжуулж тоглоомын үйлдэл хийх

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| Class | Ижил төрлийн object үүсгэх загвар. | class road: |
| Object | Class-аас үүссэн бодит нэгж. | wood_road = road("wood") |
| Member | Object дотор хадгалагдах шинж чанар. | self.material = material |
| __init__() | Object үүсэх үед ажилладаг эхлүүлэх функц. | def __init__(self, material): |
| Method | Class дотор тодорхойлсон функц. | pump.refill("food") |

## Ашиглах команд ба жишээнүүд

| Код | Юу хийдэг вэ? |
| --- | --- |
| class road: | Road төрлийн class үүсгэнэ. |
| def __init__(self, material): | Object үүсэхэд материал хадгална. |
| self.material = material | Object-ийн шинж чанарыг хадгална. |
| wood_road = road("wood") | Road class-аас object үүсгэнэ. |
| pump.refill("food") | Object-ийн method-ийг дуудна. |

## Жишээ код

```python
class road:
    def __init__(self, material):
        self.material = material
wood_road = road("wood")
player.build(wood_road)
pump.refill("food")
```

## Түвшин бүрийн тайлбар

### Level 1: Creating a Class

Зорилго: Талбайн бүх үр тариаг цуглуулж, class ашиглан өвсний овоог бүтээ.

Гол санаа: Class ашиглан өвсний овооны object үүсгэж `build()` функцэд дамжуулна.

### Level 2: Class Members

Зорилго: Талбайн материалуудыг цуглуулж, замуудыг бүтээ.

Гол санаа: `__init__()` ашиглан замын материал гэх мэт шинж чанарыг object-д хадгална.

### Level 3: Class Methods

Зорилго: Талбайн материалуудыг цуглуулж тахиануудад шинэ байшингууд барь.

Гол санаа: Тахианы байшинд өнгө, хэмжээ зэрэг шинж чанар оноож барина.

### Level 4: Class Functions

Зорилго: Үхрүүдийн тэвшнүүдийн хажууд байрлах насосны объектуудын функцуудыг идэвхжүүлж ус, хоолыг нь дахин дүүрг.

Гол санаа: Object-ийн method дотор нөхцөл ашиглан хоол эсвэл ус дүүргэнэ.

## Нийтлэг алдаа

| Алдаа | Яагаад буруу вэ? | Зөв хэлбэр |
| --- | --- | --- |
| class road | `:` тэмдэг дутуу. | class road: |
| def __init__(material): | `self` параметр дутуу. | def __init__(self, material): |
| self.material == material | Утга оноохдоо `=` ашиглана. | self.material = material |
| pump.refill | Method дуудахад `()` хэрэгтэй. | pump.refill("food") |

## Алдаа гарвал шалгах зүйлс

1. Команд, хувьсагч, функцийн нэр зөв бичигдсэн үү?
2. `()` хаалт, `:` тэмдэг, `[]` эсвэл `{}` зөв ашиглагдсан уу?
3. Текст утга хашилтын дотор байна уу?
4. Indentation буюу мөрийн зай зөв байна уу?
5. Кодын дараалал газрын зураг дээрх үйлдэлтэй таарч байна уу?
6. `Run` дарсны дараа аль мөрөөс буруу үр дүн гарч байгааг ажигласан уу?

## Дасгал

1. `class box:` гэж class үүсгээд нэг шинж чанар хадгал.
2. `wood_road = road("wood")` мөр object хэрхэн үүсгэж байгааг тайлбарла.
3. `self.material = material` мөрийн зүүн, баруун талын ялгааг тайлбарла.
4. Object-ийн method дуудах жишээ нэгийг бич.

## Өөрийгөө шалгах асуултууд

1. Class гэж юу вэ?
2. Object гэж юу вэ?
3. `__init__()` хэзээ ажилладаг вэ?
4. `self` ямар үүрэгтэй вэ?
5. Method ба энгийн функцийн ялгаа юу вэ?

## Санах гол санаа

Class нь object үүсгэх загвар бөгөөд object бүр өөрийн шинж чанар, method-той байж чадна.
