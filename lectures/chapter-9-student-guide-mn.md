# Бүлэг 9: Класс ба Объект (Class & Object)

> Тоглоомын зорилго: Энэ бүлэгт бид өөрсдөө шинэ "зүйлс" (зам, байшин, насос) бүтээж, тэднийг хүссэнээрээ ажиллуулж сурна! 🚀

# Алхам 1: Класс гэж юу вэ? (Легоны заавар)

Класс (Class) гэдэг нь ижил төрлийн зүйлсийг олноор нь хийхэд зориулсан загвар буюу зааварчилгаа (схем) юм. Жишээ нь, Лего тоглоомын машин угсрах заавар ном байж болно.

Объект (Object) гэдэг нь тэр зааврыг хараад ширээн дээрээ яг таг угсарч бэлэн болгосон бодит тоглоом юм.

**📐 Заавар (Класс) бэлдэх:**

```python
class road:
    def __init__(self, material):
        self.material = material
```

**🏎️ Заавраас бодит зүйл (Объект) гаргаж авах:**

```python
wood_road = road("wood")   # Модон зам
stone_road = road("stone") # Чулуун зам
```

| Ойлголт | Тоглоомын хэлээр | Жишээ код |
| --- | --- | --- |
| Класс (Class) | Зүйлс угсрах Легоны заавар | `class road:` |
| Объект (Object) | Заавраар угсарсан Бодит тоглоом | `wood_road = road("wood")` |
| Шинж чанар | Тоглоомын өнгө, хэмжээ, материал | `self.material` |

> **💡 Гол санаа:**
> Класс = Зааварчилгаа ном, Объект = Талбай дээр харагдаж байгаа бодит зам эсвэл байшин.

# Алхам 2: __init__() ашиглах (Материал бэлтгэгч)

`__init__()` бол объект дөнгөж үүсэх мөчид автоматаар ажилладаг тусгай функц юм. Энэ нь Лего угсарч эхлэх үед "Энэ замд ямар материал ашиглах вэ?" гэдгийг шууд шийдэж өгдөг.

```python
class road:
    def __init__(self, material):
        self.material = material # Замын материалыг энд хадгална

# Объектыг амилуулах
wood_road = road("wood")
```

**⚙️ Цаанаа яаж ажилладаг вэ?**

1. Чи кодондоо `road("wood")` гэж бичнэ.
2. `__init__` функц автоматаар ажиллана.
3. Тухайн замд `"wood"` (мод) гэдэг материалыг нааж өгнө.

**🏠 Олон шинж чанар өгөх үед:**

Байшинд өнгө, хэмжээг нь зэрэг зааж өгч болно.

```python
class house:
    def __init__(self, color, size):
        self.color = color
        self.size = size

my_house = house("red", "big") # Улаан, том байшин
player.speak(my_house.color)   # Тоглогч "red" гэж хэлнэ!
```

> **⚠️ Анхаарах зүйл:**
> `__init__` функц дотор `self` гэдэг үгийг заавал хамгийн түрүүнд бичнэ!

# Алхам 3: self гэж юу вэ? (Миний / Өөрийн)

`self` гэдэг нь тухайн объектын "Миний" эсвэл "Өөрийн" гэсэн өмчлөх үг юм. Объект болгон "Энэ бол миний материал", "Энэ бол миний өнгө" гэж өөрийнхөө шинж чанарыг хадгалахад `self`-ийг ашигладаг.

```python
class pump:
    def __init__(self, item_type):
        self.item_type = item_type # Миний төрөл
    
    def refill(self, amount):
        player.speak("Дүүргэж байна: " + self.item_type)

water_pump = pump("water")
water_pump.refill(5)
```

**🖥️ Дэлгэц дээр гарах үг:**

```
Дүүргэж байна: water
```

| Код | Яг юу гэсэн үг вэ? |
| --- | --- |
| `self.item_type` | Энэ насосны өөрийнх нь төрөл (Ус уу, хоол уу) |
| `water_pump.refill(5)` | water_pump насосны дүүргэх чадварыг дуудах |

> **⚠️ Санамж:**
> `self.material = material` (Нэг тэнцүү) гэвэл утга оноож өгнө. `==` (Хоёр тэнцүү)-ийг зөвхөн `if` нөхцөл шалгахад хэрэглээрэй.

# Алхам 4: Метод (Method) ашиглах (Объектын чадвар)

Метод (Method) гэдэг нь класс дотор бичсэн функц буюу тухайн объектын хийж чадах үйлдэл юм. Хэрэв бид амьтан үүсгэсэн бол тэр амьтан "дуугарах", "хоол идэх" чадвартай байна.

```python
class animal:
    def __init__(self, name):
        self.name = name
    
    def speak(self):
        player.speak("Намайг " + self.name + " гэдэг!")
    
    def feed(self, food):
        player.speak(self.name + " " + food + " идэж байна 😋")

# Үхэр үүсгэх
cow = animal("Bessie")

# Үхрийн чадваруудыг ажиллуулах (Метод дуудах)
cow.speak()           # Намайг Bessie гэдэг!
cow.feed("grass")     # Bessie grass идэж байна 😋
```

**Метод ба Энгийн функцийн ялгаа:**

| Метод (Method) | Энгийн функц |
| --- | --- |
| Класс дотор нуугдаж байдаг | Классын гадна ил задгай байдаг |
| Заавал тухайн объектод харьяалагдана | Биеэ даагаад шууд ажиллаж чадна |
| `cow.speak()` гэж цэгээр дууддаг | `player.move_forward()` шиг дууддаг |

# Алхам 5: Тоглоомын түвшинд хэрэглэсэн нь

**Level 1: Өвсний овоо үүсгэх**

Класс ашиглан өвсний овооны объект үүсгээд, тоглогчийн `build()` функцэд дамжуулж талбайд барьсан.

```python
class haystack:
    def __init__(self, size):
        self.size = size

small_hay = haystack("small")
player.build(small_hay)
```

**Level 2: Замын материал хадгалах**

`__init__()` ашиглан замд мод, чулуу гэсэн материал хадгалж, X тэмдэглэгээн дээр замаа тавьсан.

**Level 3-4: Автомат насос ажиллуулах**

Насосны `refill()` чадварыг дуудаж, үхэрнүүдэд хоол, ус дүүргэж өгсөн.

```python
pump = machine()
pump.refill("food") # Бараан X дээр хоол дүүргэх
```

# 🛑 Нийтлэг гаргадаг алдаанууд (Анхаар!)

| Буруу код | Яагаад алдсан бэ? | Зөв код |
| --- | --- | --- |
| `class road` | Классын нэрний ард хоёр цэг мартаж болохгүй! | `class road:` |
| `def __init__(material):` | `self` гэдэг үгийг хамгийн түрүүнд бичихээ мартсан. | `def __init__(self, material):` |
| `self.material == material` | Утга өгөхдөө нэг л тэнцүү (=) бичнэ. | `self.material = material` |
| `pump.refill` | Насосыг ажиллуулахын тулд ард нь хаалт `()` заавал хэрэгтэй. | `pump.refill("food")` |

# 🏠 Гэрийн даалгавар (Өөрийгөө сориорой)

## Даалгавар 1: Шинэ хайрцаг бүтээх

"box" гэдэг заавар үүсгээд, түүнд улаан өнгө хадгалж, тоглогчоор хэлүүл.

```python
class box:
    def __init__(self, color):
        self.color = color

red_box = box("red")
player.speak(red_box.color)
```

## Даалгавар 2: Тоглоомон муур амилуулах

Муурын класс үүсгээд, "Kitty" гэдэг нэртэй муурны объект бүтээгээрэй.

```python
class animal:
    def __init__(self, name):
        self.name = name

cat = animal("Kitty")
player.speak(cat.name)
```

## Даалгавар 3: Насосны чадварыг дуудах

Насос үүсгээд, түүнийг ажиллуулах кодыг гүйцээж бич.

```python
class pump:
    def __init__(self, item):
        self.item = item
    
    def refill(self):
        player.speak("Дүүргэж байна: " + self.item)

# Энд объектоо үүсгэж, чадварыг нь дуудаарай
water_pump = pump("water")
water_pump.refill()
```
