# Бүлэг 9

## Class ба object

CLASSES AND OBJECTS

---

# Энэ хичээлээр юу сурах вэ?

- Class гэж юу болохыг ойлгох
- Class-аас object үүсгэх
- Object-ийн шинж чанар буюу member хадгалах
- `__init__()` ашиглан object эхлүүлэх
- Class method тодорхойлж дуудах

---

# Гол ойлголтууд

| Ойлголт | Тайлбар |
| --- | --- |
| Class | Ижил төрлийн object үүсгэх загвар. |
| Object | Class-аас үүссэн бодит нэгж. |
| Member | Object дотор хадгалагдах шинж чанар. |
| __init__() | Object үүсэх үед ажилладаг эхлүүлэх функц. |
| Method | Class дотор тодорхойлсон функц. |

---

# Жишээ код

```python
class road:
    def __init__(self, material):
        self.material = material
wood_road = road("wood")
player.build(wood_road)
pump.refill("food")
```

---

# Ашиглах командууд

| Код | Үйлдэл |
| --- | --- |
| `class road:` | Road төрлийн class үүсгэнэ. |
| `def __init__(self, material):` | Object үүсэхэд материал хадгална. |
| `self.material = material` | Object-ийн шинж чанарыг хадгална. |
| `wood_road = road("wood")` | Road class-аас object үүсгэнэ. |
| `pump.refill("food")` | Object-ийн method-ийг дуудна. |

---

# Level 1: Creating a Class

Зорилго:

Талбайн бүх үр тариаг цуглуулж, class ашиглан өвсний овоог бүтээ.

Гол санаа:

Class ашиглан өвсний овооны object үүсгэж `build()` функцэд дамжуулна.

---

# Level 2: Class Members

Зорилго:

Талбайн материалуудыг цуглуулж, замуудыг бүтээ.

Гол санаа:

`__init__()` ашиглан замын материал гэх мэт шинж чанарыг object-д хадгална.

---

# Level 3: Class Methods

Зорилго:

Талбайн материалуудыг цуглуулж тахиануудад шинэ байшингууд барь.

Гол санаа:

Тахианы байшинд өнгө, хэмжээ зэрэг шинж чанар оноож барина.

---

# Level 4: Class Functions

Зорилго:

Үхрүүдийн тэвшнүүдийн хажууд байрлах насосны объектуудын функцуудыг идэвхжүүлж ус, хоолыг нь дахин дүүрг.

Гол санаа:

Object-ийн method дотор нөхцөл ашиглан хоол эсвэл ус дүүргэнэ.

---

# Нийтлэг алдаа

| Буруу | Зөв |
| --- | --- |
| `class road` | `class road:` |
| `def __init__(material):` | `def __init__(self, material):` |
| `self.material == material` | `self.material = material` |
| `pump.refill` | `pump.refill("food")` |

---

# Алдаа гарвал шалгах зүйлс

1. Нэрс зөв бичигдсэн үү?
2. Хаалт, цэг, `:` тэмдэг зөв байна уу?
3. Текст хашилттай байна уу?
4. Indentation зөв байна уу?
5. Кодын дараалал газрын зурагтай таарч байна уу?

---

# Ангийн богино дасгал

1. `class box:` гэж class үүсгээд нэг шинж чанар хадгал.
2. `wood_road = road("wood")` мөр object хэрхэн үүсгэж байгааг тайлбарла.
3. `self.material = material` мөрийн зүүн, баруун талын ялгааг тайлбарла.
4. Object-ийн method дуудах жишээ нэгийг бич.

---

# Өөрийгөө шалгах асуултууд

1. Class гэж юу вэ?
2. Object гэж юу вэ?
3. `__init__()` хэзээ ажилладаг вэ?
4. `self` ямар үүрэгтэй вэ?
5. Method ба энгийн функцийн ялгаа юу вэ?

---

# Дүгнэлт

Class нь object үүсгэх загвар бөгөөд object бүр өөрийн шинж чанар, method-той байж чадна.

Санах дараалал:

1. Газрын зургаа ажигла.
2. Шаардлагатай өгөгдлөө тодорхойл.
3. Командаа зөв дарааллаар бич.
4. `Run` дарж шалга.
5. Алдааг мөр мөрөөр нь зас.
