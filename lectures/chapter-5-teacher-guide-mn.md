# Бүлэг 5: Жагсаалт үүсгэх

Эх сурвалж: `src/data/chapters/chapter-5.ts` доторх Chapter 5-ийн сургалтын агуулга.

## Материалын хэрэглээ

- Зориулалт: багшийн лекц, ангийн дадлага, богино үнэлгээ
- Сэдэв: list, `append()`, жагсаалт нийлүүлэх, индекс, жагсаалтын утга оноох
- Нийт хугацаа: ойролцоогоор 90 минут
- Хэрэглэх хэлбэр: эхлээд багш үндсэн ойлголтыг тайлбарлаж, дараа нь сурагчид Level 1-Level 6 даалгаврыг платформ дээр гүйцэтгэнэ.

## Хичээлийн зорилго

Энэ бүлгээр сурагчид олон холбоотой утгыг нэг жагсаалтад хадгалах, нэмэх, нийлүүлэх, индексээр авах, тодорхой байрлалд утга оноох чадвартай болно.

## Суралцах үр дүн

Хичээлийн дараа сурагч дараах чадвартай болсон байна:

- Хоосон жагсаалт үүсгэх
- `append()` ашиглан жагсаалтад утга нэмэх
- Тоон болон текст жагсаалтыг ялгах
- Хоёр жагсаалтыг `+` оператороор нийлүүлэх
- Индекс 0-оос эхэлдэг гэдгийг хэрэглэх
- Жагсаалтын тодорхой байрлалд утга оноох

## Урьдчилсан шаардлага

- Компьютер ашиглах суурь чадвар
- Keyboard ашиглан текст бичих чадвар

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| List | Олон утгыг дарааллаар хадгалдаг бүтэц | `eggs = []` |
| append() | Жагсаалтад шинэ утга нэмнэ | `eggs.append(blue_eggs)` |
| Index | Жагсаалтын байрлал | `basket[0]` |
| List combining | Жагсаалтуудыг нийлүүлэх | `mixture = liquids + vegetables` |
| Assignment | Тодорхой индекс дээр утга оноох | `red_eggs[kelly] = 2` |

## Ашиглах командууд

```python
eggs = []
eggs.append(blue_eggs)
mixture = liquids + vegetables
player.place(eggs)
basket[0]
red_eggs[kelly] = 2
```

## Багшийн тайлбар

### 1. Үндсэн санаа

Жагсаалтыг дараалсан тасалгаатай хайрцагтай зүйрлэ.

### 2. Самбарын тайлбар

Эхний байрлал 1 биш 0 гэдгийг олон удаа сануул.

### 3. Ангийн чиглүүлэг

`append()` нь жагсаалтын төгсгөлд нэмдэг гэдгийг богино demo-оор харуул.

Сурагчдаас кодоо ажиллуулахын өмнө төлөвлөгөө хэлүүлэх, ажиллуулсны дараа үр дүнг кодын мөртэй холбож тайлбарлуулах дадлыг тогтмол хэрэглэнэ.

- Өндөгний тоонуудыг нэг нэгээр нь жагсаалтад нэмэхэд жагсаалт хэрхэн өсөж байгааг самбар дээр бич.
- Код бичихээс өмнө сурагчдаар эхний 2-3 алхмыг амаар хэлүүлнэ.
- `Run` дарсны дараа алдаа гарвал кодыг мөр мөрөөр нь газрын зурагтай харьцуулуулна.
