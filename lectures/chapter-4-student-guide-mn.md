# Алхам 1: Давталт гэж юу вэ? (Ижил кодыг олон удаа)

Давталт гэдэг нь ижил кодыг олон удаа ажиллуулах бүтэц юм.

Ямар нэг зүйлийг 5 удаа хийх гэж бодъё:

```python
# Буруу арга (5 мөр код)
player.move_forward()
player.move_forward()
player.move_forward()
player.move_forward()
player.move_forward()
```

```python
# Зөв арга (2 мөр код)
for x in range(5):
    player.move_forward()
```

> **Гол санаа:**
> Давталт ашиглавал код богино, цэгцтэй, алдаа багатай болно.

---

# Алхам 2: While давталт (Нөхцөл үнэн үед)

`while` давталт нь нөхцөл үнэн байх үед давтана.

```python
count = 0
while count < 3:
    player.move_forward()
    count += 1
```

**Яаж ажилладаг вэ?**

1. `count = 0` — тоолуур эхлүүлнэ
2. `count < 3` — нөхцөл шалгана (0 < 3 = үнэн)
3. `player.move_forward()` — дүрийг урагшлуулна
4. `count += 1` — тоолуурыг 1-ээр нэмнэ (одоо 1)
5. Дахин нөхцөл шалгана... (1 < 3 = үнэн)
6. Давталт дуусах үед (3 < 3 = худал)

| Код | Юу хийдэг вэ? |
| --- | --- |
| `count = 0` | Тоолуур эхлүүлнэ. |
| `while count < 4:` | Нөхцөл үнэн үед давтана. |
| `count += 1` | Тоолуурыг нэгээр нэмнэ. |

> **Анхаарах:**
> `while count < 3` гэж бичвэл алдаа гарна. `:` тэмдэг заавал хэрэгтэй.

---

# Алхам 3: For давталт (Тодорхой тоогоор)

`for` давталт нь тодорхой тоогоор давтана.

```python
for x in range(3):
    player.move_forward()
```

**`range(3)` гэдэг нь:**
- 0, 1, 2 гэсэн тоонууд өгнө
- 3 удаа давтана

**Давталтын дугаар ашиглах:**

```python
for x in range(4):
    player.move_forward(x + 1)
```

| Давталт | x утга | Алхамын тоо |
| --- | --- | --- |
| 1-р удаа | 0 | 1 алхам |
| 2-р удаа | 1 | 2 алхам |
| 3-р удаа | 2 | 3 алхам |
| 4-р удаа | 3 | 4 алхам |

> **Зөвлөмж:**
> `range(4)` гэдэг нь 4 удаа давтахыг заана. 0-оос эхэлж 3 хүртэл.

**Indentation (Мөрийн зай):**

Давталтын доторх кодыг зай авч бичих ёстой. Энэ нь Python-д "Энэ код давталтын дотор байна" гэж хэлж байгаа дохио юм.

```python
for x in range(3):
    player.move_forward()      # ✅ Зайтай — давталтын дотор
    player.turn_left()         # ✅ Зайтай — давталтын дотор

player.speak("Done!")          # ❌ Зайгүй — давталтын гадна
```

**Буруу жишээ:**

```python
for x in range(3):
player.move_forward()          # ❌ Алдаа! Зайгүй байна
```

**Зөв жишээ:**

```python
for x in range(3):
    player.move_forward()      # ✅ 4 зай эсвэл 1 Tab
```

# Алхам 4: Тоглоомын түвшинд хэрэглэх

**Level 1: While Loops**

While давталт ашиглан өндөг цуглуулах давтагдсан үйлдлүүдийг богиносгоно.

```python
count = 0
while count < 6:
    player.collect_item()
    count += 1
```

**Level 2: For Loop**

For давталт ашиглан төөрдөг байшингийн давтагдсан хөдөлгөөнийг бичнэ.

```python
for x in range(4):
    player.move_forward()
    player.turn_right()
```

**Level 3: More Complex Looping**

Хөдөлгөөн, эргэлт, услах командыг давталтын дотор зөв дарааллаар байрлуулна.

```python
for x in range(3):
    player.move_forward()
    player.water()
    player.turn_left()
```

**Level 4: For Loop Sequence**

`range()`-ийн утга өөрчлөгдөхөд давталтын алхам бүр дээр өөр тоо ашиглаж болно.

```python
for x in range(4):
    player.move_forward(x + 1)
```

# Алхам 5: Нийтлэг алдаа (Анхаарах зүйлс)

| Алдаа | Яагаад буруу вэ? | Зөв хэлбэр |
| --- | --- | --- |
| `while count < 3` | `:` тэмдэг дутуу. | `while count < 3:` |
| `count =+ 1` | Тоолуур нэмэх хэлбэр буруу. | `count += 1` |
| `for x in range(3)` | `:` тэмдэг дутуу. | `for x in range(3):` |
| `player.move_forward()` зайгүй | Indentation буруу. | `    player.move_forward()` |

# Quiz: Өөрийгөө шалгаарай

## Асуулт 1
`while` ба `for` давталтын ялгаа юу вэ?

- А) Ялгаагүй, хоёул адилхан
- Б) `while` = нөхцөл үнэн үед, `for` = тодорхой тоогоор
- В) `while` = текстэд, `for` = тоонд
- Г) `while` = хурдан, `for` = удаан

**Зөв хариулт:** Б
**Тайлбар:** `while` нөхцөл үнэн байх үед давтана, `for` тодорхой тоогоор давтана.

## Асуулт 2
`range(4)` хэдэн удаа давтах вэ?

- А) 3 удаа
- Б) 4 удаа
- В) 5 удаа
- Г) 0 удаа

**Зөв хариулт:** Б
**Тайлбар:** `range(4)` нь 0, 1, 2, 3 гэсэн 4 утга өгч, 4 удаа давтана.

## Асуулт 3
`count += 1` яагаад хэрэгтэй вэ?

- А) Тоолуурыг багасгахын тулд
- Б) Тоолуурыг нэмэхийн тулд
- В) Давталтыг зогсоохын тулд
- Г) Юу ч хийхгүй

**Зөв хариулт:** Б
**Тайлбар:** `count += 1` нь тоолуурыг 1-ээр нэмнэ. Үгүй бол давталт мөнхрөнө.

## Асуулт 4
Indentation буруу байвал юу болох вэ?

- А) Код илүү хурдан ажиллана
- Б) `IndentationError` алдаа гарна
- В) Код зөв ажиллана
- Г) Компьютер уншихгүй

**Зөв хариулт:** Б
**Тайлбар:** Python-д indentation заавал зөв байх ёстой. Буруу бол `IndentationError` гарна.

## Асуулт 5
Давталт ашиглахын гол давуу тал юу вэ?

- А) Код илүү урт болно
- Б) Код богино, цэгцтэй болно
- В) Код илүү удаан ажиллана
- Г) Алдаа илүү гарна

**Зөв хариулт:** Б
**Тайлбар:** Давталт ашиглавал ижил кодыг олон удаа бичих шаардлагагүй, код богино болно.

## Асуулт 6
Дараах код ямар үр дүн гаргах вэ?


- А) 1 удаа урагшлана

- В) 3 удаа урагшлана
