# Бүлэг 4: Давталт

## Хичээлийн сэдэв
**Давталт ашиглан ижил үйлдлийг хэрхэн олон удаа ажиллуулах вэ?**

## Зорилго
Энэ хичээлийн дараа сурагчид:

- `while` давталтын үндсэн бүтэц ойлгоно
- `for x in range(...)` ашиглан тодорхой тоогоор давтана
- Давталтын тоолуур шинэчилнэ
- Давталт дотор хөдөлгөөн, эргэлт, услах зэрэг команд байрлуулна
- Indentation буюу мөрийн зайг зөв ашиглана
- Давталт ашиглан кодын мөрийн тоог багасгана

---

## 1. Давталт гэж юу вэ?

**Давталт** гэдэг нь ижил кодыг олон удаа ажиллуулах бүтэц юм.

Жишээ:

```python
for x in range(3):
    player.move_forward()
```

Энэ код `player.move_forward()` командыг 3 удаа ажиллуулна.

Давталт ашигласнаар:

- Давтагдсан код багасна
- Код уншихад цэвэрхэн болно
- Алдаа гаргах магадлал багасна
- Нэг хэвийн хөдөлгөөнийг хурдан бичиж болно

---

## 2. While loop

`while` давталт нь нөхцөл үнэн байх үед ажиллана.

```python
count = 0

while count < 3:
    player.move_forward()
    count += 1
```

Энэ код дараах байдлаар ажиллана:

1. `count` нь `0`-оос эхэлнэ
2. `count < 3` үнэн тул доторх код ажиллана
3. `count += 1` нь тоолуурыг нэгээр нэмнэ
4. `count` 3 болох үед нөхцөл худал болж давталт зогсоно

---

## 3. For loop

`for` давталт нь тодорхой тоогоор давтахад тохиромжтой.

```python
for x in range(4):
    player.move_forward()
```

Энэ код дүрийг 4 удаа урагшлуулна.

`range(4)` нь 4 удаагийн давталт үүсгэнэ.

---

## 4. Тоолуур гэж юу вэ?

Тоолуур нь давталт хэд явсныг хадгалдаг хувьсагч юм.

```python
count = 0
while count < 4:
    player.water()
    count += 1
```

`count += 1` мөрийг мартах юм бол `while` давталт зогсохгүй байж болно.

---

## 5. Indentation

Давталтын дотор ажиллах кодыг зай авч бичнэ.

Зөв:

```python
for x in range(3):
    player.move_forward()
    player.turn_left()
```

Буруу:

```python
for x in range(3):
player.move_forward()
player.turn_left()
```

Python-д indentation нь кодын бүтцийг заадаг тул маш чухал.

---

## 6. Давталтын дугаарыг ашиглах

`for` давталтын хувьсагчийг алхам бүр дээр ашиглаж болно.

```python
for x in range(4):
    player.move_forward(x + 1)
```

Энэ код дараах утгуудыг ашиглана:

- Эхний давталт дээр `x + 1` нь `1`
- Дараагийн давталт дээр `2`
- Дараагийн давталт дээр `3`
- Сүүлийн давталт дээр `4`

## 7. Game-based coding жишээ

Доорх код давталт ашиглан дөрвөлжин замаар хөдөлнө.

```python
import player

for x in range(4):
    player.move_forward()
```

## 8. Түвшин бүрийн тайлбар

### Level 1: While Loops

Зорилго: `while` давталт ашиглан 6 мөрөөс ихгүй кодоор жүчээн доторх бүх өндгийг цуглуул.

Гол санаа: Давтагдсан өндөг цуглуулах үйлдлийг `while` давталтаар богиносгоно.

### Level 2: For Loop

Зорилго: `for` давталт ашиглан 6-аас илүүгүй мөр кодоор бутны төөрдөг байшингаас гар.

Гол санаа: Төөрдөг байшингийн давтагдсан хөдөлгөөнийг `for` давталтаар бичнэ.

### Level 3: More Complex Looping

Зорилго: 14-өөс илүүгүй мөр код ашиглан талбайгаар явж ургацаа услаад гарц руу хүр.

Гол санаа: Хөдөлгөөн, эргэлт, услах командыг давталтын дотор зөв дарааллаар байрлуулна.

### Level 4: For Loop Sequence

Зорилго: 4-өөс илүүгүй мөр код бичээд үр тариагаа цуглуулж төөрдөг байшингаас гар.

Гол санаа: `range()`-ийн утга өөрчлөгдөхөд давталтын алхам бүр дээр өөр тоо ашиглаж болно.

## 9. Дасгал 1

```python
    player.move_forward()
```

## 10. Дасгал 2

