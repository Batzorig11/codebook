# Бүлэг 3

## Үндсэн операторууд

BASIC OPERATORS

---

# Энэ хичээлээр юу сурах вэ?

- Тоон утгууд дээр `+`, `-`, `*`, `/` оператор ашиглах
- Хувьсагчийн утгыг `-=`, `*=` зэрэг оператороор шинэчлэх
- Тоон нийлбэр, ялгавар, үржвэрийг `speak()` функцээр харуулах
- Текст формат ашиглан тоо болон үгийг өгүүлбэрт оруулах

---

# Гол ойлголтууд

| Ойлголт | Тайлбар |
| --- | --- |
| Оператор | Утгууд дээр тооцоо хийдэг тэмдэг. |
| Нэмэх | Тоонуудыг нийлүүлнэ. |
| Хасах | Нэг утгаас нөгөө утгыг хасна. |
| Үржүүлэх | Утгыг хэд дахин өсгөнө. |
| String format | Текст дотор хувьсагчийн утга оруулна. |

---

# Жишээ код

```python
cows = 3
goats = 2
pigs = 4
player.speak(cows + goats + pigs)
player.speak("there are %d eggs" % egg_basket)
```

---

# Ашиглах командууд

| Код | Үйлдэл |
| --- | --- |
| `player.speak(cows)` | Хувьсагчийн утгыг хэлүүлнэ. |
| `player.speak(cows + goats + pigs)` | Нийлбэрийг тооцоод хэлүүлнэ. |
| `white_eggs -= 2` | Цагаан өндөгний тооноос 2-ыг хасна. |
| `red_eggs *= 2` | Улаан өндөгний утгыг 2 дахин өсгөнө. |
| `player.place(bag1)` | Тооцоолсон утгыг байрлуулна. |

Амьтдын тоог хувьсагчид хадгалаад нийлбэрийг `+` оператороор олно.

Өндөгний тоог нэмэх, муудсан өндгийг хасах, шаардлагатай бол үржүүлэх дадлага хийнэ.

# Level 4: Constants and Practice

Зорилго:

Сагс дүүрэн өндгөө авчраад савнуудад хадгалж, хэдэн өндөг байгааг хэлцгээе!

Гол санаа:

Тогтмол болон хувьсагчийн утгыг тооцоонд ашиглаж үр дүнг байрлуулж, хэлүүлнэ.

# Нийтлэг алдаа

| Буруу | Зөв |
| --- | --- |
| `player.speak("cows + goats")` | `player.speak(cows + goats)` |
| `white_eggs =- 2` | `white_eggs -= 2` |
| `red_eggs =* 2` | `red_eggs *= 2` |
| `"%d eggs" % (name)` | `"%s" % name` |

---

# Алдаа гарвал шалгах зүйлс

1. Нэрс зөв бичигдсэн үү?
2. Хаалт, цэг, `:` тэмдэг зөв байна уу?
3. Текст хашилттай байна уу?
4. Indentation зөв байна уу?
5. Кодын дараалал газрын зурагтай таарч байна уу?

---

# Ангийн богино дасгал

1. `apples = 5`, `pears = 3` гэж үүсгээд нийлбэрийг хэлүүл.
2. `eggs = 10` утгаас 4-ийг `-=` ашиглан хас.
3. `red_eggs = 3` утгыг `*=` ашиглан 2 дахин өсгө.
4. `player.speak("there are %d eggs" % eggs)` хэлбэрээр өгүүлбэр гарга.

---

# Өөрийгөө шалгах асуултууд

1. `+` оператор юу хийдэг вэ?
2. `-=` оператор ямар үед хэрэгтэй вэ?
3. `red_eggs *= 2` дараа утга яаж өөрчлөгдөх вэ?
4. `%d` болон `%s` хоёрын ялгаа юу вэ?
5. Яагаад тооцоог хашилтын дотор бичиж болохгүй вэ?

# Дүгнэлт

Операторууд нь хувьсагчийн утгыг тооцоолж, шинэ үр дүн гаргахад ашиглагддаг.

Санах дараалал:

1. Газрын зургаа ажигла.
2. Шаардлагатай өгөгдлөө тодорхойл.
3. Командаа зөв дарааллаар бич.
4. `Run` дарж шалга.
5. Алдааг мөр мөрөөр нь зас.
