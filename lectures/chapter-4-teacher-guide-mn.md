## Суралцах үр дүн

Хичээлийн дараа сурагч дараах чадвартай болсон байна:

- `for x in range(...)` бүтэц ашиглах
- Давталтын доторх кодыг indentation-тэй бичих
- Давталт ашиглан хөдөлгөөн, эргэлт, услах командыг давтах

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| Давталт | Ижил кодыг олон удаа ажиллуулах бүтэц | `for x in range(3):` |
| While loop | Нөхцөл үнэн байх үед давтана | `while count < 4:` |
| For loop | Тодорхой тоогоор давтана | `for x in range(4):` |
| Тоолуур | Давталтын явцыг хадгална | `count += 1` |
| Indentation | Давталтын доторх кодыг зай авч бичих | `    player.move_forward()` |

## Ашиглах командууд

```python
count = 0
while count < 4:
count += 1
for x in range(3):
player.move_forward(2)
player.move_forward(x + 1)
```

## Багшийн тайлбар

### 1. Үндсэн санаа

Давталтыг “ижил ажлыг олон удаа давтах заавар” гэж энгийнээр эхлүүл.

### 2. Самбарын тайлбар

Indentation буруу бол давталтын доторх код танигдахгүй гэдгийг самбар дээр харуул.

### 3. Ангийн чиглүүлэг

`range(4)` нь 4 удаа давтана, харин утгууд нь 0, 1, 2, 3 гэдгийг онцол.

Сурагчдаас кодоо ажиллуулахын өмнө төлөвлөгөө хэлүүлэх, ажиллуулсны дараа үр дүнг кодын мөртэй холбож тайлбарлуулах дадлыг тогтмол хэрэглэнэ.

## Түвшин бүрийн материал

### Level 1: While Loops

Зорилго: While давталт ашиглан зөвхөн 6 мөр код бичээд жүчээн доторх бүх өндгийг цуглуулаад түвшнийг дуусга.

Багшийн чиглүүлэг:

- `count = 0`, нөхцөл, `count += 1` гурвыг хамтад нь ойлгуул. Тоолуур нэмэхгүй бол давталт дуусахгүй гэдгийг тайлбарла.
- Код бичихээс өмнө сурагчдаар эхний 2-3 алхмыг амаар хэлүүлнэ.
- `Run` дарсны дараа алдаа гарвал кодыг мөр мөрөөр нь газрын зурагтай харьцуулуулна.

Асуух асуулт:

- Энэ түвшинд хамгийн чухал шинэ санаа юу вэ?
- Кодын аль мөр газрын зураг дээрх аль үйлдэлтэй таарч байна вэ?
- Дарааллыг өөрчилбөл үр дүн хэрхэн өөрчлөгдөх вэ?

### Level 2: For Loop

Зорилго: For давталт ашиглан 6-аас илүүгүй мөр кодоор бутны төөрдөг байшингаар явж гарц руу хүр.

Багшийн чиглүүлэг:

- `for` давталт нь давтах тоо тодорхой үед илүү тохиромжтойг харуул.
- Код бичихээс өмнө сурагчдаар эхний 2-3 алхмыг амаар хэлүүлнэ.
- `Run` дарсны дараа алдаа гарвал кодыг мөр мөрөөр нь газрын зурагтай харьцуулуулна.

## Сурагчийн бие даалтын даалгавар

1. `for x in range(5):` ашиглан таван удаа давтах жишээ бич.
2. `while count < 3:` давталтын бүтцийг бүтнээр нь бич.
3. Давталт ашиглаагүй 5 мөр кодыг давталттай богиносго.
4. Өнөөдрийн хамгийн их алдсан нэг алдаагаа бичээд, зассан аргаа тайлбарла.
