# Бүлэг 4

## Давталт

LEARNING LOOPS

---

# Энэ хичээлээр юу сурах вэ?

- `while` давталтын үндсэн бүтэц ойлгох
- `for x in range(...)` ашиглан тодорхой тоогоор давтах
- Давталтын тоолуур шинэчлэх
- Давталт дотор хөдөлгөөн, эргэлт, услах зэрэг команд байрлуулах
- Давталт ашиглан кодын мөрийн тоог багасгах

---

# Гол ойлголтууд

| Ойлголт | Тайлбар |
| --- | --- |
| Давталт | Ижил кодыг олон удаа ажиллуулах бүтэц. |
| While loop | Нөхцөл үнэн байх үед давтана. |
| For loop | Тодорхой тоогоор давтана. |
| Тоолуур | Давталт хэд явсныг хадгална. |
| Indentation | Давталтын доторх кодыг зай авч бичнэ. |

---

# Жишээ код

```python
count = 0
while count < 3:
    player.move_forward()
    count += 1
for x in range(4):
    player.move_forward(x + 1)
```

---

# Ашиглах командууд

| Код | Үйлдэл |
| --- | --- |
| `count = 0` | Тоолуур эхлүүлнэ. |
| `while count < 4:` | Нөхцөл үнэн үед давтана. |
| `count += 1` | Тоолуурыг нэгээр нэмнэ. |
| `for x in range(3):` | Гурван удаа давтана. |
| `player.move_forward(x + 1)` | Давталтын дугаар ашиглан алхмын тоог өөрчилнө. |

---

# Level 1: While Loops

Зорилго:

While давталт ашиглан зөвхөн 6 мөр код бичээд жүчээн доторх бүх өндгийг цуглуулаад түвшнийг дуусга.

Гол санаа:

`while` давталт ашиглан өндөг цуглуулах давтагдсан үйлдлүүдийг богиносгоно.

---

# Level 2: For Loop

Зорилго:

For давталт ашиглан 6-аас илүүгүй мөр кодоор бутны төөрдөг байшингаар явж гарц руу хүр.

Гол санаа:

`for` давталт ашиглан төөрдөг байшингийн давтагдсан хөдөлгөөнийг бичнэ.

---

# Level 3: More Complex Looping

Зорилго:

14-өөс илүүгүй мөр код ашиглан талбайгаар явж ургацаа услаад гарц руу хүр.

Гол санаа:

Хөдөлгөөн, эргэлт, услах командыг давталтын дотор зөв дарааллаар байрлуулна.

---

# Level 4: For Loop Sequence

Зорилго:

4-өөс илүүгүй мөр код бичээд үр тариагаа цуглуулж төөрдөг байшингаас гар.

Гол санаа:

`range()`-ийн утга өөрчлөгдөхөд давталтын алхам бүр дээр өөр тоо ашиглаж болно.

---

# Нийтлэг алдаа

| Буруу | Зөв |
| --- | --- |
| `while count < 3` | `while count < 3:` |
| `count =+ 1` | `count += 1` |
| `for x in range(3)` | `for x in range(3):` |
| `player.move_forward() зайгүй` | `    player.move_forward()` |

---

# Алдаа гарвал шалгах зүйлс

1. Нэрс зөв бичигдсэн үү?
2. Хаалт, цэг, `:` тэмдэг зөв байна уу?
3. Текст хашилттай байна уу?
4. Indentation зөв байна уу?
5. Кодын дараалал газрын зурагтай таарч байна уу?

---

# Ангийн богино дасгал

1. `for x in range(3):` ашиглан дүрийг гурван удаа урагшлуул.
2. `while count < 4:` ашиглан дөрвөн удаа давтах код бич.
3. Давталтын дотор `turn_left()` нэмээд үр дүнг ажигла.
4. `player.move_forward(x + 1)` яагаад алхам бүр дээр өөр утга авч байгааг тайлбарла.

---

# Өөрийгөө шалгах асуултууд

1. `while` ба `for` давталтын ялгаа юу вэ?
2. `range(4)` хэдэн удаа давтах вэ?
3. `count += 1` яагаад хэрэгтэй вэ?
4. Indentation буруу байвал юу болох вэ?
5. Давталт ашиглахын гол давуу тал юу вэ?

---

# Дүгнэлт

Давталт нь давтагдсан үйлдлийг богино, цэгцтэй, алдаа багатай бичихэд тусалдаг.

Санах дараалал:

1. Газрын зургаа ажигла.
2. Шаардлагатай өгөгдлөө тодорхойл.
3. Командаа зөв дарааллаар бич.
4. `Run` дарж шалга.
5. Алдааг мөр мөрөөр нь зас.
