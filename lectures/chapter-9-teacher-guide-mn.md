## Хичээлийн зорилго

Энэ бүлгээр сурагчид class-ийг объект үүсгэх загвар гэж ойлгож, object-ийн шинж чанар болон method ашиглан тоглоомын объект бүтээх үндсэн чадвартай болно.

## Суралцах үр дүн

Хичээлийн дараа сурагч дараах чадвартай болсон байна:

- Class ба object-ийн ялгааг тайлбарлах
- Class-аас object үүсгэх
- `__init__()` функцийн үүргийг ойлгох
- `self` ашиглан object-ийн шинж чанар хадгалах
- Object-ийн method дуудах
- Object-ийг `build()` зэрэг функцэд дамжуулах

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| Class | Ижил төрлийн object үүсгэх загвар | `class road:` |
| Object | Class-аас үүссэн бодит нэгж | `wood_road = road("wood")` |
| Member | Object доторх шинж чанар | `self.material = material` |
| __init__() | Object үүсэхэд ажиллах эхлүүлэх функц | `def __init__(self, material):` |
| Method | Object дээр ажиллах функц | `pump.refill("food")` |

## Ашиглах командууд

```python
class road:
def __init__(self, material):
self.material = material
wood_road = road("wood")
player.build(wood_road)
pump.refill("food")
```

## Багшийн тайлбар

### 1. Үндсэн санаа

Class-ийг зураг төсөл, object-ийг тэр зураг төслөөр хийсэн бодит зүйлтэй зүйрлэ.

### 2. Самбарын тайлбар

`self` нь тухайн object өөрөө гэсэн санааг илэрхийлдэг гэж энгийнээр тайлбарла.

### 3. Ангийн чиглүүлэг

Class-ийн синтакс сурагчдад шинэ тул indentation ба `:` тэмдгийг онцгой шалгуул.

Сурагчдаас кодоо ажиллуулахын өмнө төлөвлөгөө хэлүүлэх, ажиллуулсны дараа үр дүнг кодын мөртэй холбож тайлбарлуулах дадлыг тогтмол хэрэглэнэ.

## Түвшин бүрийн материал

Багшийн чиглүүлэг:

- Энгийн class үүсгээд object-ийг `build()` функцэд дамжуулах урсгалыг харуул.
- Код бичихээс өмнө сурагчдаар эхний 2-3 алхмыг амаар хэлүүлнэ.
- `Run` дарсны дараа алдаа гарвал кодыг мөр мөрөөр нь газрын зурагтай харьцуулуулна.

## Сурагчийн бие даалтын даалгавар

1. `class box:` гэсэн энгийн class бич.
2. `__init__()` ашиглан `color` шинж чанар хадгал.
3. `my_box = box("red")` мөр юу хийж байгааг тайлбарла.
4. Өнөөдрийн хамгийн их алдсан нэг алдаагаа бичээд, зассан аргаа тайлбарла.

## Нийтлэг алдаа ба засах арга

| Алдаа | Шалтгаан | Засах арга |
| --- | --- | --- |
| `class road` | `:` тэмдэг дутуу | `class road:` |
| `def __init__(material):` | `self` параметр дутуу | `def __init__(self, material):` |
| `self.material == material` | Оноохдоо `=` ашиглана | `self.material = material` |
| `pump.refill` | Method дуудахад хаалт хэрэгтэй | `pump.refill("food")` |
