## Хичээлийн зорилго

Энэ бүлгээр сурагчид тодорхой нөхцөл үнэн үед л код ажиллуулах, нөхцөлийг давталт болон жагсаалттай хамт хэрэглэх чадвартай болно.

## Суралцах үр дүн

Хичээлийн дараа сурагч дараах чадвартай болсон байна:

- `if` нөхцөлийн бүтэц бичих
- `==` ба `!=` операторын ялгааг тайлбарлах
- Жагсаалтын утгуудыг харьцуулах
- `len()` ашиглан жагсаалтын урт шалгах
- Давталт дотор нөхцөл ашиглах
- Нөхцөлөөс хамааран өөр өөр үйлдэл хийх

## Урьдчилсан шаардлага

- Компьютер ашиглах суурь чадвар

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| If statement | Нөхцөл үнэн үед код ажиллуулна | `if x == 0:` |
| == | Тэнцүү эсэхийг шалгана | `basket[0] == basket[1]` |
| != | Ялгаатай эсэхийг шалгана | `basket[1] != basket[2]` |
| len() | Жагсаалтын уртыг буцаана | `len(items)` |
| Conditional loop | Давталт дотор нөхцөл шалгах | `for x in range(3): if x == 0:` |

if basket[0] == basket[1]:
if basket[1] != basket[2]:
if len(items) < 5:

if x == 0:

## Багшийн тайлбар

### 1. Үндсэн санаа

Нөхцөлийг “хэрэв ... бол ...” гэсэн өгүүлбэрээр эхлүүл.

### 2. Самбарын тайлбар

`=` нь оноолт, `==` нь шалгалт гэдгийг заавал ялгуул.

### 3. Ангийн чиглүүлэг

Нөхцөлийн дараах `:` ба indentation хоёр хамт хэрэгтэйг харуул.

Сурагчдаас кодоо ажиллуулахын өмнө төлөвлөгөө хэлүүлэх, ажиллуулсны дараа үр дүнг кодын мөртэй холбож тайлбарлуулах дадлыг тогтмол хэрэглэнэ.

## Түвшин бүрийн материал

### Level 1: Basic If Statement

Зорилго: Талбай дээрх бүх өндгийг цуглуулж, if илэрхийллийн нөхцөлийг ашиглан бие биетэй нь харьцуул.

Багшийн чиглүүлэг:

- Өндөгнүүдийн утгыг харьцуулж үнэн/худал үр дүнг сурагчдаар таалгуул.
- Код бичихээс өмнө сурагчдаар эхний 2-3 алхмыг амаар хэлүүлнэ.
- `Run` дарсны дараа алдаа гарвал кодыг мөр мөрөөр нь газрын зурагтай харьцуулуулна.

Асуух асуулт:

- Энэ түвшинд хамгийн чухал шинэ санаа юу вэ?
- Кодын аль мөр газрын зураг дээрх аль үйлдэлтэй таарч байна вэ?
- Дарааллыг өөрчилбөл үр дүн хэрхэн өөрчлөгдөх вэ?

### Level 2: Complex If Statement

- Цуглуулсан зүйлсийг нөхцөлөөр нэгтгэхдээ аль нөхцөл биелж байгааг мөр мөрөөр шалгуул.

## Сурагчийн бие даалтын даалгавар

1. `if score == 10:` гэсэн жишээ нөхцөл бич.
2. `!=` ашигласан нэг жишээ зохио.
3. `items = [1, 2, 3]` жагсаалтын уртыг шалгах код бич.
4. Өнөөдрийн хамгийн их алдсан нэг алдаагаа бичээд, зассан аргаа тайлбарла.

## Нийтлэг алдаа ба засах арга

| Алдаа | Шалтгаан | Засах арга |
| --- | --- | --- |
| `if x = 1:` | `=` нь оноолт | `if x == 1:` |
| `if x == 1` | `:` тэмдэг дутуу | `if x == 1:` |
| `len[items]` | `len` функц тул хаалт хэрэгтэй | `len(items)` |
| Доторх код зайгүй | If блок танигдахгүй | `    player.speak(...)` |

## Богино шалгалт

1. `if` ямар үед доторх кодоо ажиллуулдаг вэ?
2. `=` ба `==` хоёрын ялгаа юу вэ?
3. `!=` юу шалгадаг вэ?
4. `len(items)` юу буцаадаг вэ?
5. Давталт дотор нөхцөл ашиглахын давуу тал юу вэ?

## Хариултын түлхүүр

1. Нөхцөл үнэн үед.
2. `=` утга онооно, `==` тэнцүү эсэхийг шалгана.
3. Хоёр утга ялгаатай эсэхийг шалгана.
4. Жагсаалтын уртыг тоогоор буцаана.
5. Давталтын алхам бүрт өөр үйлдэл сонгох боломж өгнө.
