# Бүлэг 1

## Python програмчлалын эхлэл

Chapter 1-ийн гол ойлголт, командууд, дасгалууд

---

# Энэ хичээлээр юу сурах вэ?

- Code Editor дээр Python команд бичих
- `Run` товч дарж кодоо ажиллуулах
- `player` модулийн функцуудыг ашиглах
- Дүрийг урагшлуулах, зүүн/баруун тийш эргүүлэх
- Командын дарааллыг зөв төлөвлөх

---

# Код гэж юу вэ?

Код бол компьютерт өгч байгаа тодорхой заавар.

Тоглоомын дүр өөрөө шийдвэр гаргахгүй.

Чиний бичсэн командын дагуу л хөдөлнө.

```python
player.move_forward()
```

---

# Code Editor ба Run

1. Code Editor дээр командаа бичнэ.
2. `Run` товч дарна.
3. Дүр ямар үйлдэл хийж байгааг ажиглана.
4. Алдаа гарвал кодоо засаж дахин ажиллуулна.

---

# Функц гэж юу вэ?

Функц гэдэг нь тодорхой үйлдэл хийдэг команд.

Chapter 1 дээр бид `player` модулийн функцуудыг ашиглана.

```python
player.function_name()
```

Жишээ:

```python
player.turn_left()
player.turn_right()
```

---

# Командын дараалал

Python код дээрээс доошоо мөр мөрөөрөө ажилладаг.

```python
player.move_forward()
player.turn_right()
player.move_forward()
```

Энэ код:

1. Нэг алхам урагш явна.
2. Баруун тийш эргэнэ.
3. Дахин нэг алхам урагш явна.

---

# Яагаад дараалал чухал вэ?

Доорх хоёр код ижил үр дүнтэй байхгүй.

```python
player.move_forward()
player.turn_right()
```

```python
player.turn_right()
player.move_forward()
```

Эхний мөр өөрчлөгдөхөд дүрийн зам өөрчлөгдөнө.

---

# Аргумент гэж юу вэ?

Аргумент гэдэг нь функцэд дамжуулж буй утга.

```python
player.move_forward(3)
```

Энд байгаа `3` нь алхмын тоо.

Энэ команд дүрийг гурван алхам урагшлуулна.

---

# Аргумент ашиглахын давуу тал

Энэ код:

```python
player.move_forward()
player.move_forward()
player.move_forward()
```

Дараах кодтой ижил:

```python
player.move_forward(3)
```

Код богино, ойлгомжтой болно.

---

# Chapter 1-ийн командууд

| Команд | Үйлдэл |
| --- | --- |
| `player.move_forward()` | Нэг алхам урагшилна. |
| `player.move_forward(3)` | Гурван алхам урагшилна. |
| `player.turn_left()` | Зүүн тийш эргэнэ. |
| `player.turn_right()` | Баруун тийш эргэнэ. |

---

# Нэмэлт командууд

| Команд | Үйлдэл |
| --- | --- |
| `player.push()` | Өмнөх чулууг түлхэнэ. |
| `player.speak('Hello')` | `Hello` гэж хэлүүлнэ. |
| `player.build('bridge')` | Гүүр барина. |

---

# Level 1: Starting Out

Зорилго: анхны Python командаа бичих.

```python
player.move_forward()
```

Санах зүйл:

- `()` хаалт заавал бичнэ.
- Кодоо бичээд `Run` дарна.
- Нэг мөр код нэг үйлдэл хийж байгааг ажиглана.

---

# Level 2: Movement with Functions

Зорилго: дүрийг хөдөлгөж гарц руу хүргэх.

```python
player.move_forward()
player.turn_left()
player.turn_right()
```

Код бичихээс өмнө:

- Дүр аль зүг рүү харж байна вэ?
- Гарц хаана байна вэ?
- Эхлээд урагшлах уу, эргэх үү?

---

# Level 3: Collecting Items

Зорилго: газрын зураг дээрх жимснүүдийг цуглуулах.

Шинэ ойлголт: функцийн аргумент.

```python
player.move_forward(3)
```

Ижил командыг олон удаа бичихийн оронд алхмын тоог хаалт дотор өгч болно.

---

# Level 4: Pushing Objects

Зорилго: замд байгаа чулууг түлхэх.

```python
player.push()
```

Анхаарах зүйл:

- Дүр чулуу руу харсан байх ёстой.
- Эхлээд зөв байрлалд очно.
- Дараа нь `player.push()` гэж бичнэ.

---

# Level 5: Printing on Screen

Зорилго: X тэмдэг дээр очоод `Hello` гэж хэлүүлэх.

```python
player.speak('Hello')
```

`Hello` нь текст тул хашилтын дотор бичигдэнэ.

Зөв:

```python
player.speak('Hello')
```

Буруу:

```python
player.speak(Hello)
```

---

# Level 6: Building Objects

Зорилго: мод цуглуулж гүүр барих.

```python
player.build('bridge')
```

Анхаарах зүйл:

- Модны дээгүүр алхвал мод цугларна.
- Гүүр барихын өмнө модоо цуглуулна.
- `bridge` гэдэг үгийг яг зөв бичнэ.
- `bridge` нь текст тул хашилтын дотор байна.

---
