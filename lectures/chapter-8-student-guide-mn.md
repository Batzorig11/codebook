# Бүлэг 8: Dictionary ашиглах

Энэ бүлэгт түлхүүр ба утга гэсэн хосоор мэдээлэл хадгалдаг dictionary ашиглаж сурна.

## Энэ бүлгээр юу сурах вэ?

- Хоосон dictionary үүсгэх
- Түлхүүрээр утга хадгалах ба авах
- Dictionary-ээс утга устгах
- Dictionary ашиглан объект байрлуулах, тарих, услах
- `items()` ашиглан dictionary дээгүүр давтах
- Dictionary-г өөрийн функцтэй хамт ашиглах

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| Dictionary | Түлхүүр-утга хосоор мэдээлэл хадгалдаг бүтэц. | bag = {} |
| Key | Утгыг олох нэр. | bag["Apples"] |
| Value | Түлхүүрт хадгалсан мэдээлэл. | bag["Apples"] = 5 |
| del | Dictionary-ээс түлхүүр устгана. | del crate["Pipes"] |
| items() | Түлхүүр ба утгыг хамтад нь давтана. | for name, number in materials.items(): |

## Ашиглах команд ба жишээнүүд

| Код | Юу хийдэг вэ? |
| --- | --- |
| bag = {} | Хоосон dictionary үүсгэнэ. |
| bag["Apples"] = 5 | Apples түлхүүрт 5 гэсэн утга хадгална. |
| player.speak(bag) | Dictionary-г харуулна. |
| del crate["Pipes"] | Pipes түлхүүрийг устгана. |
| for name, number in materials.items(): | Бүх түлхүүр-утга хосоор давтана. |

## Жишээ код

```python
bag = {}
bag["Apples"] = 4
bag["Oranges"] = 3
player.speak(bag)
for name, number in bag.items():
    player.speak("%s: %d" % (name, number))
```

## Түвшин бүрийн тайлбар

### Level 1: Creating a Dictionary

Зорилго: Бүх жимсийг цуглуулж толь (dictionary)-д хадгалаад хэдийг авсанаа тоол.

Гол санаа: Жимсний тоог dictionary-д түлхүүрээр хадгална.

### Level 2: Using a Dictionary

Зорилго: Толь ашиглан талбайд үрийг суулга.

Гол санаа: Үрийн мэдээллийг dictionary-ээс авч талбайд тарина.

### Level 3: More Complex Operations

Зорилго: Агуулахын бүх хайрцгийг шалгаж, хайрцаг бүрээс хог хаягдлыг устга.

Гол санаа: Агуулахын хайрцаг доторх хэрэггүй зүйлсийг `del` ашиглан устгана.

### Level 4: Placing Objects Using Dictionaries

Зорилго: Талбайн бүх ургацыг хурааж, толь ашиглан агуулахад хадгал.

Гол санаа: Ургацын тоог dictionary-д хадгалаад агуулахад байрлуулна.

### Level 5: Custom Functions Using Dictionaries

Зорилго: Талбайг туулж мод тарих, усалах захиалгат функц ашигла.

Гол санаа: Dictionary утгуудыг өөрийн функцийн аргумент болгон ашиглаж талбайг боловсруулна.

### Level 6: Iterating Over Dictionaries

Зорилго: Талбайн бүх материалыг олоод цуглуулсан эд зүйлсээ тоолсны дараа тухайн саванд нь хадгал.

Гол санаа: `items()` ашиглан цуглуулсан материал бүрийн нэр ба тоог давталтаар хэлүүлнэ.

## Нийтлэг алдаа

| Алдаа | Яагаад буруу вэ? | Зөв хэлбэр |
| --- | --- | --- |
| bag = [] | Энэ нь list, dictionary биш. | bag = {} |
| bag[Apples] = 5 | Текст түлхүүр хашилтгүй байна. | bag["Apples"] = 5 |
| bag("Apples") | Dictionary-д `[]` ашиглаж хандана. | bag["Apples"] |
| for name in materials.items(): | Түлхүүр ба утгыг хоёуланг авах бол хоёр хувьсагч хэрэгтэй. | for name, number in materials.items(): |

## Алдаа гарвал шалгах зүйлс

1. Команд, хувьсагч, функцийн нэр зөв бичигдсэн үү?
2. `()` хаалт, `:` тэмдэг, `[]` эсвэл `{}` зөв ашиглагдсан уу?
3. Текст утга хашилтын дотор байна уу?
4. Indentation буюу мөрийн зай зөв байна уу?
5. Кодын дараалал газрын зураг дээрх үйлдэлтэй таарч байна уу?
6. `Run` дарсны дараа аль мөрөөс буруу үр дүн гарч байгааг ажигласан уу?

## Дасгал

1. `bag = {}` үүсгээд `bag["Apples"] = 5` гэж утга нэм.
2. Dictionary доторх утгыг `player.speak(bag)` ашиглан харуул.
3. `del bag["Apples"]` ашиглахад юу болохыг тайлбарла.
4. `for name, number in bag.items():` давталтын үүргийг тайлбарла.

## Өөрийгөө шалгах асуултууд

1. Dictionary ба list хоёрын ялгаа юу вэ?
2. Key гэж юу вэ?
3. `bag["Apples"] = 5` мөр юу хийж байна вэ?
4. `del` ямар үүрэгтэй вэ?
5. `items()` ямар үед хэрэгтэй вэ?

## Санах гол санаа

Dictionary нь нэртэй мэдээллийг түлхүүрээр нь хурдан хадгалж, авч ашиглахад тохиромжтой.
