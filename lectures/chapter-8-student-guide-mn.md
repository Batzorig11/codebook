# Бүлэг 8: Dictionary ашиглах

> Мэдээллийг (нэр, нас, дүн) зүгээр нэг жагсаалтаар биш, тусгай "шошго" буюу key ашиглан ухаалгаар хадгалж, удирдаж сурна.

---

# Алхам 1: Dictionary гэж юу вэ? (Үүсгэх & Нэмэх)

List-д мэдээллийг зүгээр л цуглуулдаг бол, Dictionary-д мэдээлэл бүрд **шошго** нааж хадгалдаг.

## Key буюу Шошго гэж юу вэ?

Бодит амьдрал дахь **шургуулганы хайрцаг**тай адил. Шургуулга бүрт нэр (шошго) байх бөгөөд түүний дотор зүйл хадгалагдана.

| Шошго (Key) | Доторх зүйл (Value) |
| --- | --- |
| "нэр" | "Алиса" |
| "нас" | 15 |
| "дүн" | 95 |

## Dictionary үүсгэх

```python
student = {}
```

Энэ нь хоосон dictionary (толь бичиг) үүсгэж байна.

## Мэдээлэл нэмэх (Шошго наах)

```python
student["нэр"] = "Алиса"
student["нас"] = 15
student["дүн"] = 95
```

> 💡 **Зөвлөмж:** Dictionary-д мэдээлэл нэмэхдээ `[]` хаалт ашиглана. `"нэр"` гэдэг нь шошго (key), `"Алиса"` гэдэг нь утга (value).

## Жишээ код

```python
import player

student = {}
student["нэр"] = "Алиса"
student["нас"] = 15

player.speak(student)
```

**Гаралт:**
```
{'нэр': 'Алиса', 'нас': 15}
```

---

# Алхам 2: Мэдээлэл авах ба Аюулгүй шалгах

Хадгалсан мэдээллээ авахдаа индекс дугаар биш, нөгөө наасан шошгоороо нь дуудаж авна.

## Мэдээлэл авах

```python
player.speak(student["нэр"])
player.speak(student["нас"])
```

**Гаралт:**
```
Алиса
15
```

## Байхгүй шошгийг авах (Алдаа!)

```python
# ❌ Алдаа! "хичээл" гэдэг шошго байхгүй
player.speak(student["хичээл"])
```

**Үр дүн:** `KeyError` алдаа гарна.

## Аюулгүй шалгах (if)

```python
if "нас" in student:
    player.speak(student["нас"])
else:
    player.speak("Нас байхгүй")
```

> ⚠️ **Анхаарах:** Эхлээд шошго байгаа эсэхийг шалгаад, дараа нь авах нь аюулгүй!

---

# Алхам 3: Мэдээлэл өөрчлөх ба Устгах

Толь бичигт байгаа хуучин мэдээллийг шинэчлэх, эсвэл хэрэггүй болбол устгахад маш амархан.

## Утга өөрчлөх

```python
student["дүн"] = 95
student["дүн"] = 98  # Шинэчилнэ!

player.speak(student["дүн"])
```

**Гаралт:**
```
98
```

## Мэдээлэл устгах

```python
del student["дүн"]

player.speak(student)
```

**Гаралт:**
```
{'нэр': 'Алиса', 'нас': 15}
```

> 🎯 **Гол санаа:** `del` гэдэг нь "устга" гэсэн үг. Шошго болон түүний утгыг хамтад нь устгана.

---

# Алхам 4: Ахисан шат (List хадгалах & Function)

Dictionary дотор бүхэл бүтэн List-ийг ч хадгалж болно. Мөн түүнийгээ функц руу шууд дамжуулж ашиглана.

## Dictionary дотор List хадгалах

```python
student = {
    "нэр": "Алиса",
    "хичээл": ["Математик", "Шинжлэх ухаан", "Уран зохиол"]
}

# List-ийн эхний хичээлийг харуул
player.speak(student["хичээл"][0])
```

**Гаралт:**
```
Математик
```

## Function дотор ашиглах

```python
def мэдээлэл_харуулах(оюутан):
    player.speak("Нэр: " + оюутан["нэр"])
    player.speak("Нас: " + str(оюутан["нас"]))

student = {"нэр": "Алиса", "нас": 15}
мэдээлэл_харуулах(student)
```

**Гаралт:**
```
Нэр: Алиса
Нас: 15
```

> 💡 **Зөвлөмж:** Dictionary-г функц руу дамжуулахдаа бүх мэдээллийг нэг дор илгээж болно. Илүү цэгцтэй!

# Алхам 5: items() ашиглан бүх дүнг давтах

Оюутны бүх хичээлийн дүнг нэг бүрчлэн уншиж гаргахад `items()` давталт хэрэг болно.

## items() гэж юу вэ?

`items()` нь dictionary-ийн **бүх шошго болон утгыг хамтад нь** өгнө.

```python
scores = {"Математик": 95, "Шинжлэх ухаан": 88, "Уран зохиол": 92}

for хичээл, дүн in scores.items():
    player.speak(хичээл + ": " + str(дүн))
```

**Гаралт:**
```
Математик: 95
Шинжлэх ухаан: 88
Уран зохиол: 92
```

## Давталт яаж ажилладаг вэ?

| Давталт | хичээл (Key) | дүн (Value) |
| --- | --- | --- |
| 1-р удаа | "Математик" | 95 |
| 2-р удаа | "Шинжлэх ухаан" | 88 |
| 3-р удаа | "Уран зохиол" | 92 |

> 🎯 **Гол санаа:** `items()` ашиглахдаа 2 хувьсагч ашиглана. Эхнийх нь шошго, хоёр дахь нь утга.

# Сонголт: List үү? Dictionary уу?

Ямар тохиолдолд юу ашиглах вэ?

| Тооцоолох | List [] | Dictionary {} |
| --- | --- | --- |
| **Юу хадгалах** | Жагсаалт (дэд, дунд, дээд) | Нэртэй мэдээлэл (нэр: Алиса) |
| **Хэрхэн авах** | `list[0]` (индекс) | `dict["нэр"]` (шошго) |
| **Жишээ** | `[95, 88, 92]` | `{"Математик": 95}` |
| **Хэзээ ашиглах** | Дараалал чухал үед | Нэрээр хайх үед |

## Жишээ

**Жишээ 1:** Сургуулийн дүнгийн жагсаалт
```python
# ❌ List (ямар хичээл вэ? мэдэхгүй)
duns = [95, 88, 92]

# ✅ Dictionary (хичээлийн нэртэй)
duns = {"Математик": 95, "Шинжлэх ухаан": 88}
```

**Жишээ 2:** Дараалалтай тоо
```python
# ✅ List (дараалал чухал)
дараалал = ["Бат", "Сараа", "Болд"]

# ❌ Dictionary (хэрэггүй)
```

# 🎯 Quiz: Өөрийгөө шалгаарай

## Асуулт 1
Dictionary гэж юу вэ?

- А) List
- Б) key → value бүтэц
- В) Зөвхөн тоо
- Г) Зөвхөн string

**Зөв хариулт:** Б
**Тайлбар:** Dictionary нь key-value хосоор мэдээлэл хадгалдаг.

## Асуулт 2
Dictionary үүсгэх зөв хэлбэр?

- А) []
- Б) {}
- В) ()
- Г) ""

**Зөв хариулт:** Б
**Тайлбар:** Dictionary-г {} хаалтаар үүсгэнэ.

## Асуулт 3
Мэдээлэл нэмэх зөв код?

- А) student("age") = 15
- Б) student["age"] = 15
- В) student.age = 15
- Г) student{"age"} = 15

**Зөв хариулт:** Б
**Тайлбар:** Квадрат хаалт [] ашиглан key-д утга онооно.

## Асуулт 4
Dictionary-с утга авах?

- А) student["name"]
- Б) student.name
- В) student->name
- Г) student(name)

**Зөв хариулт:** А
**Тайлбар:** Квадрат хаалт [] ашиглан key-ээр утга авах.

## Асуулт 5
Байхгүй key авахад юу болох вэ?

- А) None
- Б) 0
- В) KeyError
- Г) False

**Зөв хариулт:** В
**Тайлбар:** Байхгүй key авахад KeyError алдаа гарна.

## Асуулт 6
items() юу өгдөг вэ?

- А) keys
- Б) values
- В) key-value хос
- Г) list

**Зөв хариулт:** В
**Тайлбар:** items() бүх key-value хосыг өгнө.
