# Бүлэг 2: Хувьсагч ба өгөгдлийн төрөл

> **Энэ хичээлээр:**
> Компьютерын санах ойд мэдээллийг хэрхэн нэрлэж хадгалах, өгөгдлийн төрлүүд хоорондоо ямар ялгаатай болохыг онолын хувьд гүнзгийрүүлэн сурна.

---

# Алхам 1: Хувьсагч гэж юу вэ? (Утга хадгалах)

Програмчлалд **Хувьсагч (Variable)** гэдэг нь компьютерын шуурхай санах ойд (RAM) мэдээлэл хадгалахад зориулж нээсэн "нэр хаягтай хайрцаг" юм. Бид санах ойн хэцүү хаягуудыг цээжлэхгүйн тулд түүнд өөрсдөө ойлгомжтой нэр өгдөг.

```python
planks = 4
bricks = 3
```

**Яагаад `=` тэмдгийг ашигладаг вэ?**

Үүнийг програмчлалд **Утга оноох оператор (Assignment Operator)** гэдэг. Энэ нь математикийн "тэнцүү" гэсэн ойлголт биш бөгөөд баруун талд байгаа утгыг (4) зүүн талд байгаа хувьсагчийн нэрэнд (planks) аваачиж хадгал гэсэн тушаал юм.

**Хувьсагчийг ашиглах:**

```python
player.place(planks)
```

**Яагаад хувьсагч хэрэгтэй вэ?**

Энэ код нь `player.place(4)` гэж бичсэнтэй яг ижил ажиллана. Гэхдээ кодонд 4 гэдэг тоо шууд байвал "4 ширхэг юу хаана байрлуулах вэ?" гэдэг нь тодорхойгүй байна. Хувьсагч ашигласнаар код уншиж буй хүнд болон компьютерт "4 ширхэг банз (planks) байрлуулж байна" гэдэг утгыг маш тодорхой, ойлгомжтой болгодог.

| Ойлголт | Онолын нэршил | Үүрэг | Жишээ |
| --- | --- | --- | --- |
| Хувьсагч | Variable | Санах ойд мэдээлэл хадгалах нэрлэсэн хайрцаг. | `planks = 4` |
| Тоон өгөгдөл | Integer (int) | Бүхэл тоон утга хадгалах төрөл. | `bricks = 3` |
| Текстэн өгөгдөл | String (str) | Тэмдэгтүүдийн цуглуулга, үг, өгүүлбэр. | `bag1 = "Pumpkin"` |

---

# Алхам 2: Тоон ба текст утга (Ялгааг ойлгох)

Компьютер санах ойд байгаа мэдээллийг зөв боловсруулахын тулд тэдгээрийг шинж чанараар нь ялгадаг. Үүнийг **Өгөгдлийн төрөл (Data Types)** гэнэ.

**Тоон өгөгдөл (Integer эсвэл Int):** Бутархай биш бүхэл тоонуудыг хэлнэ. Компьютер үүнийг шууд математик тооцоололд ашиглаж чаддаг.

```python
apples = 5
pears = 3
total = apples + pears  # Математик үйлдэл хийгдэж 8 гарна
player.speak(total)
```

**Текстэн өгөгдөл (String эсвэл Str):** Үсэг, тэмдэгт, өгүүлбэрийн цуглуулга.

```python
bag1 = "Pumpkin"
player.speak(bag1)
```

**Яагаад `planks = four` гэж бичиж болохгүй вэ?**

`four` гэдэг нь хашилтгүй бичигдсэн учраас компьютер үүнийг тоо биш, өөр нэгэн хувьсагчийн нэр байна гэж бодно. Гэтэл санах ойд `four` гэдэг нэртэй хувьсагч урьдчилж үүсгээгүй бол компьютер түүнийг олж чадахгүй тул **NameError (Нэрийн алдаа)** заана.

**Текст яагаад хашилтанд байх ёстой вэ?**

Компьютер бол машин учраас чиний бичсэн `Pumpkin` гэдэг үгийг кодын тушаал уу эсвэл зүгээр текст үг үү гэдгийг ялгаж мэдэхгүй. Хэрэв чи `""` эсвэл `''` хашилт хэрэглэвэл компьютер "Аан, энэ бол кодын тушаал биш, зүгээр л текстэн өгөгдөл байна" гэдгийг шууд таньдаг.

```python
# Зөв: Компьютер үүнийг String (текст) гэж танина
bag1 = "Pumpkin"

# Буруу: Компьютер "Pumpkin" гэдэг нэртэй хувьсагч хайна
bag1 = Pumpkin  # Алдаа! Pumpkin гэдэг хувьсагч санах ойд олдсонгүй
```

# Алхам 3: Коммент ашиглах (Тайлбар бичих)

**Коммент (Comment)** гэдэг нь кодын дотор бичигдсэн боловч компьютерт биш, зөвхөн хүнд зориулагдсан тайлбар бичих арга юм.

```python
# Компьютер энэ мөрийг уншилгүй алгасна
# player.move_forward()

# Энэ мөрийг компьютер уншиж ажиллуулна
player.turn_left()
```

**Яагаад коммент хэрэгтэй вэ?**

Python-ийн хөрвүүлэгч (Interpreter) кодыг дээрээс доош уншихдаа `#` тэмдгийг хармагцаа тухайн мөрөнд байгаа зүйлсийг кодыг ажиллуулах процессоос бүрэн хасдаг. Үүнийг онолд **Код идэвхгүй болгох** эсвэл **Тэмдэглэл үлдээх** гэнэ.

> **Онолын зөвлөмж:**
> Сайн хөгжүүлэгч болохын тулд кодынхоо логикийг комментоор тайлбарлаж сурах хэрэгтэй. Энэ нь том хэмжээний төсөл дээр ажиллахад кодын бүтэц, зорилгыг хурдан ойлгоход тусалдаг.

# Алхам 4: Тоглоомын командууд (Хувьсагчтай хослуулах)

Хувьсагчид хадгалсан өгөгдлийг функцүүдийн хаалтан дотор **Аргумент** болгон дамжуулж, програмаа илүү уян хатан болгож болно.

| Код | Юу хийдэг вэ? (Онолын тайлбар) |
| --- | --- |
| `player.water()` | Тэвш эсвэл ургацыг услах функц. |
| `player.collect("water")` | Худгаас ус цуглуулах функц (`"water"` гэсэн String аргумент авна). |
| `player.open()` | Хаалга, авдар зэрэг объектуудыг нээх функц. |
| `player.close()` | Нээгдсэн объектыг хаах функц. |
| `player.place(wheat)` | `wheat` хувьсагчид хадгалагдсан өгөгдлийг байрлуулах функц. |

**Жишээ кодны онолын задлан шинжилгээ:**

```python
planks = 4           # 1. Тоон өгөгдөл (Integer) хадгалсан хувьсагч
bricks = 3           # 2. Тоон өгөгдөл (Integer) хадгалсан хувьсагч
wheat = 5            # 3. Тоон өгөгдөл (Integer) хадгалсан хувьсагч
bag1 = "Pumpkin"     # 4. Текстэн өгөгдөл (String) хадгалсан хувьсагч

player.place(bag1)       # 5. 'bag1' хувьсагчийн утга болох "Pumpkin"-ийг дамжуулж байна
player.collect("water")  # 6. Хувьсагч биш, шууд "water" гэсэн String утгыг дамжуулж байна
```

**Түвшин бүрийн тайлбар:**

- **Level 1:** Сав авч 3 тэвш услах дарааллыг үүсгэнэ.
- **Level 2:** Comment ашиглан кодыг хэрхэн идэвхгүй болгох онолыг сурна.
- **Level 3:** Ус цуглуулах функц дуудаж, дараа нь ургамал услах дарааллыг хэрэгжүүлнэ.
- **Level 4:** Объектын төлөвийг өөрчлөх `open()` болон `close()` функцийг ашиглана.
- **Level 5:** Янз бүрийн утгуудыг хувьсагчид оноож (assignment) сурна.
- **Level 6:** Хувьсагчийг функцийн аргумент болгон дамжуулах онолыг хэрэгжүүлнэ.
- **Level 7:** Текстэн өгөгдлийг хувьсагчид хадгалж, түүнийгээ дуудаж ашиглана.

# Дүгнэлт

Энэ бүлэгт үзсэн програмчлалын суурь онолуудыг үргэлж санаж яваарай:

- **Хувьсагч (Variable):** Мэдээллийг санах ойд нэрлэж хадгалах хайрцаг юм.
- **Утга оноох (Assignment):** `=` оператор нь баруун талын утгыг зүүн талын хувьсагчид хадгалдаг.
- **Өгөгдлийн төрөл (Data Types):** Компьютер тоог (Integer) болон текстийг (String) өөр өөрөөр харж боловсруулдаг.
- **Текстэн өгөгдөл (String):** Текстийг кодын тушаалаас ялгахын тулд үргэлж `""` эсвэл `''` хашилтад бичнэ.
- **Коммент (Comment):** `#` тэмдгээр компьютерт биш, хүнд зориулсан кодын тайлбарыг бичиж, мөрийг идэвхгүй болгодог.
- **Хувьсагчийг дамжуулах:** Хувьсагчийг функцэд аргумент болгон өгөхдөө хашилтГҮЙ бичдэг.

---

# Гол санаа

- **Хувьсагч (Variable):** Санах ойд мэдээлэл хадгалах нэрлэсэн хайрцаг.
- **Утга оноох (=):** Баруун талын утгыг зүүн талын хувьсагчид хадгална.
- **Тоо (Integer):** Шууд математик тооцоонд ашиглагддаг бүхэл тоо.
- **Текст (String):** Тэмдэгтүүд бөгөөд үргэлж `""` эсвэл `''` хашилтад бичнэ.
- **Коммент (Comment):** `#` тэмдгээр компьютерт биш, хүнд зориулж тайлбар бичнэ.
- **Аргумент болгох:** Хувьсагчийг хашилтгүй, харин текстийг хашилттай дамжуулна.

## Даалгавар 3: Коммент ашиглах

Доорх кодонд коммент (тайлбар) нэмж, аль мөрөнд хувьсагч үүсгэж, аль мөрөнд түүнийг ашиглаж байгааг онолын хувьд тэмдэглээрэй.

```python
# Энд кодоо бичнэ үү
# items нэртэй хувьсагчид 5 гэсэн Integer утга оноож байна
items = 5

# items хувьсагчийг place функцийн аргумент болгон дамжуулж байна
player.place(items)
```
