# Бүлэг 2: Хувьсагч ба өгөгдлийн төрөл

## Хичээлийн сэдэв
**Хувьсагч ашиглан мэдээллийг хэрхэн нэрлэж хадгалах вэ?**

## Зорилго
Энэ хичээлийн дараа сурагчид:

- Хувьсагч гэж юу болохыг тайлбарлана
- Тоон болон текст утгыг хувьсагчид хадгална
- Comment ашиглан кодын мөрийг тайлбарлана эсвэл түр идэвхгүй болгоно
- `collect()`, `water()`, `open()`, `close()`, `place()` командуудыг хэрэглэнэ
- Хувьсагчийг function-ийн argument болгон дамжуулна
- Кодын утгыг нэрээр нь уншиж ойлгодог болно

---

## 1. Хувьсагч гэж юу вэ?

**Хувьсагч** гэдэг нь утгад өгсөн нэр юм.

Жишээ:

```python
planks = 4
```

Энэ код `planks` гэдэг нэрэнд `4` гэсэн утга хадгалж байна.

Дараа нь `planks` нэрийг ашиглан тухайн утгыг дахин хэрэглэж болно.

---

## 2. Тоон утга хадгалах

Тоо хадгалсан хувьсагчийг тооцоонд болон function-ийн argument болгон ашиглаж болно.

```python
bricks = 3
logs = 5

player.place(bricks)
player.place(logs)
```

Анхаарах зүйлс:

- Тоог хашилтгүй бичнэ
- Хувьсагчийн нэрийг ойлгомжтой өгнө
- Утга оноохдоо `=` тэмдэг ашиглана

---

## 3. Текст утга хадгалах

Текст утгыг хашилтын дотор бичнэ.

```python
bag1 = "Pumpkin"
bag2 = "Carrot"

player.place(bag1)
player.place(bag2)
```

`"Pumpkin"` нь текст утга. Харин `bag1` нь тэр текстийг хадгалсан хувьсагчийн нэр юм.

---

## 4. Comment гэж юу вэ?

**Comment** нь кодод тайлбар үлдээх эсвэл нэг мөрийг түр ажиллуулахгүй болгоход ашиглагдана.

```python
# player.move_forward()
player.turn_left()
```

`#` тэмдэгтэй мөрийг Python ажиллуулахгүй.

Comment ашигласнаар:

- Кодын зорилгыг тайлбарлаж болно
- Алдаатай мөрийг түр унтрааж шалгаж болно
- Аль мөр хэрэгтэй, аль мөр хэрэггүйг ялгаж болно

---

## 5. Хувьсагчийг argument болгон ашиглах

Function-д шууд утга өгөхийн оронд хувьсагч дамжуулж болно.

```python
wheat = 5
player.place(wheat)
```

Энэ үед `place()` function-д `wheat` хувьсагчийн утга дамжиж байна.

Текст болон тоон утга хоёуланг ингэж дамжуулж болно.

---

## 6. Chapter 2-д ашиглах командууд

```python
player.water()
player.collect("water")
player.open()
player.close()
player.place(wheat)
```

Эдгээр командын утга:

- `player.water()` нь тэвш эсвэл ургацыг усална
- `player.collect("water")` нь худгаас ус цуглуулна
- `player.open()` нь хаалга, авдар зэрэг объектыг нээнэ
- `player.close()` нь нээсэн объектыг хаана
- `player.place(wheat)` нь хувьсагчид хадгалсан зүйлийг байрлуулна

---

## 7. Жишээ код

```python
import player

planks = 4
bricks = 3
wheat = 5
bag1 = "Pumpkin"

player.collect("water")
player.water()
player.place(bag1)
player.place(wheat)
```

## 8. Түвшин бүрийн тайлбар

### Level 1: Watering objects

Зорилго: Усны савыг авч 3 тэвшийг усаар дүүргэж түвшнийг дуусга.

Гол санаа: Усны сав авч, тэвш бүрийн өмнө зөв чиглэл рүү хараад усална.

### Level 2: Commenting code

Зорилго: Код засварлагч дээрх тайлбаруудыг өөрчилж гарц руу хүр.

Гол санаа: Comment нь кодын мөрийг түр идэвхгүй болгож чадна.

### Level 3: Collecting resources

Зорилго: Худгаас ус аваад саваа дүүргэж, 5 ургацыг бүгдийг нь усал.

Гол санаа: Эхлээд усаа цуглуулж, дараа нь `X` тэмдэг бүр дээр очиж ургацаа усална.

### Level 4: Opening and closing commands

Зорилго: Хашааг нээж талбай руу ороод жүчээний 4 үүдийг бүгдийг нь хаа.

Гол санаа: Орохдоо `open()`, ажлаа дуусгаад `close()` ашиглана.

### Level 5: Number variables

Зорилго: Банз, тоосго цуглуулаад хувьсагчид хадгал.

Гол санаа: Цуглуулсан банз, тоосгоны тоог хувьсагчид хадгална.

### Level 6: Placing objects

Зорилго: Улаан буудайг цуглуулаад хувьсагчид хадгалж, авдарт байрлуулаад хаа.

Гол санаа: Цуглуулсан улаан буудайн тоог хувьсагчид хадгалаад `place()` function-д дамжуулна.

### Level 7: String variables

Зорилго: 3 барааг тус тусад нь хувьсагчид хадгалж, авдруудыг нээж байрлуулаад хаа.

Гол санаа: Текст утга хашилтын дотор бичигдэнэ.
