# Бүлэг 2: Хувьсагч ба өгөгдлийн төрөл

Энэ бүлэгт хувьсагч ашиглан тоо, текст, цуглуулсан зүйлсийг нэрлэж хадгалах аргыг сурна.

## Энэ бүлгээр юу сурах вэ?

- Хувьсагч гэж юу болохыг тайлбарлах
- Тоон болон текст утгыг хувьсагчид хадгалах
- Тайлбар буюу comment ашиглан кодын мөрийг ажиллуулахгүй болгох
- `collect()`, `water()`, `open()`, `close()`, `place()` командуудыг хэрэглэх
- Хувьсагчийг функцийн аргумент болгон ашиглах

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| Хувьсагч | Утгад өгсөн нэр. Дараа нь тэр нэрээрээ ашиглаж болно. | planks = 4 |
| Тоон утга | Тоо хадгалсан хувьсагч. | bricks = 3 |
| Текст утга | Хашилтын дотор бичсэн үг эсвэл өгүүлбэр. | bag1 = "Pumpkin" |
| Comment | Кодод тайлбар үлдээх эсвэл мөрийг ажиллуулахгүй болгох арга. | # player.move_forward() |
| Аргумент | Функцэд дамжуулж буй утга. | player.place(wheat) |

## Ашиглах команд ба жишээнүүд

| Код | Юу хийдэг вэ? |
| --- | --- |
| player.water() | Тэвш эсвэл ургацыг усална. |
| player.collect("water") | Худгаас ус цуглуулна. |
| player.open() | Хаалга, авдар зэрэг объектыг нээнэ. |
| player.close() | Нээсэн объектыг хаана. |
| player.place(wheat) | Хувьсагчид хадгалсан зүйлийг байрлуулна. |

## Жишээ код

```python
planks = 4
bricks = 3
wheat = 5
bag1 = "Pumpkin"
player.place(bag1)
```

## Түвшин бүрийн тайлбар

### Level 1: Watering objects

Зорилго: Усны савыг авч 3 тэвшийг усаар дүүргэж түвшнийг дуусга.

Гол санаа: Усны сав авч тэвш бүрийн өмнө зөв чиглэл рүү хараад усална.

### Level 2: Commenting code

Зорилго: Код засварлагч дээрх тайлбаруудыг өөрчилж гарц руу хүр!

Гол санаа: Comment нь кодын мөрийг түр идэвхгүй болгож чадна. Аль мөр ажиллах ёстойг ялгаж сур.

### Level 3: Collecting resources

Зорилго: Худгаас ус аваад саваа дүүргээд 5 ургацыг бүгдийг нь усалж түвшнийг дуусга!

Гол санаа: Эхлээд усаа цуглуулж, дараа нь X тэмдэг бүр дээр очиж ургацаа усална.

### Level 4: Opening and closing commands

Зорилго: Хашааг нээж талбай руу ороод жүчээний 4 үүдийг бүгдийг нь хаагаад түвшнийг дуусга!

Гол санаа: Орохдоо `open()`, ажлаа дуусгаад `close()` ашиглана.

### Level 5: Number variables

Зорилго: Банз (planks), тоосго (bricks) цуглуулаад хувьсагчид хадгалж түвшнийг дуусга!

Гол санаа: Цуглуулсан банз, тоосгоны тоог хувьсагчид хадгална.

### Level 6: Placing objects

Зорилго: Талбай дээрх улаан буудайг цуглуулаад хувьсагчид хадгал, авдарт нь байрлуулаад хаагаад түвшнийг дуусга!

Гол санаа: Цуглуулсан улаан буудайн тоог хувьсагчид хадгалаад `place()` функцэд дамжуулна.

### Level 7: String variables

Зорилго: 3 барааг аваад тус тусад нь хувьсагчид хадгал, авдруудыг нээж тус бүрд нь байрлуулаад хаагаад түвшнийг дуусга!

Гол санаа: Текст утга хашилтын дотор бичигддэг. Жишээ нь `bag1 = "Pumpkin"`.

## Нийтлэг алдаа

| Алдаа | Яагаад буруу вэ? | Зөв хэлбэр |
| --- | --- | --- |
| planks = four | Тоог үгээр бичсэн. | planks = 4 |
| bag1 = Pumpkin | Текст хашилтгүй байна. | bag1 = "Pumpkin" |
| player.place("wheat") | Хувьсагчийн нэрийн оронд текст өгсөн байж болно. | player.place(wheat) |
| player.collect(water) | Текст утга хашилтгүй байна. | player.collect("water") |

## Алдаа гарвал шалгах зүйлс

1. Команд, хувьсагч, функцийн нэр зөв бичигдсэн үү?
2. `()` хаалт, `:` тэмдэг, `[]` эсвэл `{}` зөв ашиглагдсан уу?
3. Текст утга хашилтын дотор байна уу?
4. Indentation буюу мөрийн зай зөв байна уу?
5. Кодын дараалал газрын зураг дээрх үйлдэлтэй таарч байна уу?
6. `Run` дарсны дараа аль мөрөөс буруу үр дүн гарч байгааг ажигласан уу?

## Дасгал

1. `logs = 4` гэсэн хувьсагч үүсгээд `player.place(logs)` гэж ашигла.
2. `bag1 = "Pumpkin"` мөрийг `bag2 = "Carrot"` болгож өөрчилж турш.
3. Comment ашиглан нэг хөдөлгөөний мөрийг түр идэвхгүй болго.
4. Нээх, байрлуулах, хаах дарааллыг өөрийн үгээр бич.

## Өөрийгөө шалгах асуултууд

3. `#` тэмдэг кодод ямар үүрэгтэй вэ?
4. `player.place(wheat)` доторх `wheat` ямар үүрэгтэй вэ?
