# Бүлэг 5: Жагсаалт үүсгэх

> **Энэ хичээлээр:**
> Олон утгыг нэг нэрийн дор хадгалах жагсаалт буюу list ашиглаж сурна.

---

# Алхам 1: Жагсаалт гэж юу вэ? (Олон утгыг нэг нэрээр)

Жагсаалт гэдэг нь олон утгыг дарааллаар нь хадгалдаг бүтэц юм.

**Хоосон жагсаалт үүсгэх:**

```python
eggs = []
```

**Жагсаалтад утга нэмэх:**

```python
blue_eggs = 5
eggs.append(blue_eggs)
```

**Гаралт:**
```
[5]
```

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| List | Олон утгыг дарааллаар хадгална. | `eggs = []` |
| `append()` | Жагсаалтын төгсгөлд утга нэмнэ. | `eggs.append(5)` |
| Index | Жагсаалтын байрлал. 0-оос эхэлдэг. | `basket[0]` |

---

# Алхам 2: Жагсаалтад утга нэмэх (append)

`append()` функцээр жагсаалтын төгсгөлд шинэ утга нэмнэ.

```python
numbers = []
numbers.append(10)
numbers.append(20)
numbers.append(30)

player.speak(numbers)
```

**Гаралт:**
```
[10, 20, 30]
```

**Текст жагсаалт:**

```python
names = []
names.append("Alice")
names.append("Bob")

player.speak(names)
```

**Гаралт:**
```
['Alice', 'Bob']
```

> **Анхаарах:**
> `eggs.append[blue_eggs]` гэж бичвэл алдаа гарна. `append` нь функц тул `()` хэрэгтэй.

---

# Алхам 3: Жагсаалтын индекс (0-оос эхэлнэ)

Жагсаалтын байрлалыг индексээр авна. Python-д индекс **0-оос эхэлдэг**.

```python
fruits = ["Apple", "Banana", "Cherry"]

# Эхний утга (индекс 0)
player.speak(fruits[0])  # Apple

# Хоёр дахь утга (индекс 1)
player.speak(fruits[1])  # Banana

# Гурав дахь утга (индекс 2)
player.speak(fruits[2])  # Cherry
```

| Индекс | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Утга | Apple | Banana | Cherry |

**Утга өөрчлөх:**

```python
fruits[1] = "Blueberry"
# Одоо: ["Apple", "Blueberry", "Cherry"]
```

> **Гол санаа:**
> Python-д эхний утга `[0]`, хоёр дахь `[1]` гэх мэт. Энэ нь компьютерийн тооллын системтэй холбоотой.

---

# Алхам 4: Жагсаалт нийлүүлэх (+)

Хоёр жагсаалтыг `+` ашиглан нийлүүлнэ.

```python
liquids = ["water", "milk"]
vegetables = ["carrot", "potato"]

mixture = liquids + vegetables
player.speak(mixture)
```

**Гаралт:**
```
['water', 'milk', 'carrot', 'potato']
```

**Жагсаалтыг функцэд дамжуулах:**

```python
items = ["planks", "bricks"]
player.place(items)
```

> **Анхаарах:**
> `[liquids + vegetables]` гэж бичвэл илүү nested list үүсгэнэ. Зөв нь `liquids + vegetables`.

---

# Алхам 5: Тоглоомын түвшинд хэрэглэх

**Level 1: Numeric Lists**

Өндөгний тоонуудыг жагсаалтад хадгалж саванд байрлуулна.

```python
eggs = []
eggs.append(5)
eggs.append(3)
player.place(eggs)
```

**Level 2: Combining Lists**

Шингэн ба ногооны жагсаалтыг нийлүүлж шинэ бүтээгдэхүүн үүсгэнэ.

```python
liquids = ["water", "milk"]
vegetables = ["carrot"]

soup = liquids + vegetables
```

**Level 3: String Lists**

Гахайнуудын нэрийг текст жагсаалтад хадгалж, нэр бүрийг дуудна.

```python
names = ["Peggle", "Peter", "Piper"]
player.speak("Come here %s" % names[0])
```

**Level 4-6: Index ашиглах**

Жагсаалтын индекс ашиглан зөв саванд зөв утга байрлуулна.

```python
basket = [5, 3, 7]
player.speak(basket[0])  # 5
player.speak(basket[1])  # 3
```

**Нийтлэг алдаа (Анхаарах зүйлс):**

| Алдаа | Яагаад буруу вэ? | Зөв хэлбэр |
| --- | --- | --- |
| `eggs.append[blue_eggs]` | `append` функц тул `()` хэрэгтэй. | `eggs.append(blue_eggs)` |
| `basket[1]` эхний утга | Python индекс 0-оос эхэлдэг. | `basket[0]` |
| `names = Peggle, Peter` | Жагсаалт хашилт дутуу. | `names = ["Peggle", "Peter"]` |
| `mixture = [liquids + vegetables]` | Илүү nested list үүсгэнэ. | `mixture = liquids + vegetables` |

# Quiz: Өөрийгөө шалгаарай

## Асуулт 1
Жагсаалт ямар үед хэрэгтэй вэ?

- А) Зөвхөн нэг утга хадгалахад
- Б) Олон холбоотой утгыг нэг нэрээр хадгалахад
- В) Зөвхөн тооцоо хийхэд
- Г) Зөвхөн текст хадгалахад

**Зөв хариулт:** Б
**Тайлбар:** Жагсаалт нь олон холбоотой утгыг нэг нэрээр хадгалж, индексээр нь хандах боломж өгдөг.

## Асуулт 2
`append()` юу хийдэг вэ?

- А) Жагсаалтын эхэнд утга нэмнэ
- Б) Жагсаалтын төгсгөлд утга нэмнэ
- В) Жагсаалтаас утга устгана
- Г) Жагсаалтыг хоосолно

**Зөв хариулт:** Б
**Тайлбар:** `append()` функц жагсаалтын төгсгөлд шинэ утга нэмдэг.

## Асуулт 3
Python жагсаалтын эхний индекс хэд вэ?

- А) 1
- Б) 0
- В) -1
- Г) Хувьсагчийн нэр

**Зөв хариулт:** Б
**Тайлбар:** Python-д жагсаалтын эхний утгын индекс үргэлж 0 байна.

## Асуулт 4
Хоёр жагсаалтыг яаж нийлүүлэх вэ?

- А) `-` оператороор
- Б) `*` оператороор
- В) `+` оператороор
- Г) `/` оператороор

**Зөв хариулт:** В
**Тайлбар:** `+` оператороор хоёр жагсаалтыг нийлүүлж шинэ жагсаалт үүсгэнэ.

## Асуулт 5
Дараах кодны гаралтыг ол.

```python
items = ["A", "B", "C"]
player.speak(items[1])
```

- А) A
- Б) B
- В) C
- Г) Алдаа гарна

**Зөв хариулт:** Б
**Тайлбар:** Индекс 1 нь хоёр дахь утгыг заана. Эхний утга [0], хоёр дахь [1].

## Асуулт 6
Дараах код ямар үр дүн гаргах вэ?

```python
nums = []
nums.append(10)
nums.append(20)
player.speak(nums)
```

- А) 10
- Б) 20
- В) [10, 20]
- Г) []

**Зөв хариулт:** В
**Тайлбар:** `append()` нь жагсаалтын төгсгөлд нэмнэ. [10, 20] гэж харагдана.

# Дүгнэлт

Энэ бүлэгт чи:

1. Жагсаалт гэж юу болохыг ойлголоо
2. `append()` ашиглан утга нэмэхийг сурлаа
3. Жагсаалтын индекс (0-оос эхэлдэг) гэдгийг ойлголоо
4. Жагсаалт нийлүүлэх (`+`) аргыг сурлаа
5. Жагсаалтын утгыг өөрчлөхийг сурлаа
6. Жагсаалтыг тоглоомд хэрэглэхийг сурлаа

Жагсаалт нь олон холбоотой утгыг нэг нэрээр хадгалж, индексээр нь хандах боломж өгдөг.

---

# Гол санаа

- `[]` — хоосон жагсаалт үүсгэнэ
- `append()` — төгсгөлд утга нэмнэ
- `[0]` — эхний утга (индекс 0-оос эхэлнэ)
- `+` — жагсаалт нийлүүлнэ
- Жагсаалтын утгыг индексээр өөрчилж болно
