# Бүлэг 5: Жагсаалт үүсгэх

## Хичээлийн сэдэв
**List ашиглан олон утгыг нэг нэрийн дор хэрхэн хадгалах вэ?**

## Зорилго
Энэ хичээлийн дараа сурагчид:

- Хоосон list үүсгэнэ
- `append()` ашиглан list-д утга нэмнэ
- Тоон болон текст list үүсгэнэ
- List-үүдийг нийлүүлнэ
- Index ашиглан тодорхой утга авна
- List-ийн тодорхой байрлалын утгыг өөрчилнө
- List-ийг тоглоомын command-д argument болгон ашиглана

---

## 1. List гэж юу вэ?

**List** гэдэг нь олон утгыг дарааллаар нь хадгалдаг бүтэц юм.

Жишээ:

```python
eggs = [2, 4, 6]
```

Энэ list дотор гурван тоон утга байна.

List ашигласнаар холбоотой олон утгыг нэг нэрээр хадгалж болно.

---

## 2. Хоосон list үүсгэх

Хоосон list үүсгэхдээ `[]` ашиглана.

```python
eggs = []
```

Энэ үед `eggs` нэртэй list үүссэн боловч дотор нь одоогоор утга байхгүй.

---

## 3. append() ашиглах

`append()` нь list-ийн төгсгөлд шинэ утга нэмнэ.

```python
eggs = []
blue_eggs = 5

eggs.append(blue_eggs)
player.place(eggs)
```

`append()` нь function тул `()` хаалттай бичигдэнэ.

---

## 4. Тоон болон текст list

List дотор тоо, текст зэрэг олон төрлийн утга хадгалж болно.

Тоон list:

```python
counts = [3, 5, 2]
```

Текст list:

```python
names = ["Peggle", "Peter", "Piper", "Pedro"]
```

Текст утгуудыг хашилтын дотор бичнэ.

---

## 5. List-үүдийг нийлүүлэх

Хоёр list-ийг `+` оператор ашиглан нийлүүлж болно.

```python
liquids = ["water", "milk"]
vegetables = ["carrot", "pumpkin"]

mixture = liquids + vegetables
player.place(mixture)
```

Энэ үед `mixture` list дотор хоёр list-ийн бүх утга дарааллаараа орно.

---

## 6. Index гэж юу вэ?

**Index** нь list доторх утгын байрлал юм.

Python дээр index `0`-оос эхэлдэг.

```python
basket = ["blue egg", "red egg", "white egg"]

player.speak(basket[0])
player.speak(basket[1])
```

Гаралт:

```text
blue egg
red egg
```

---

## 7. List-ийн утга өөрчлөх

List-ийн тодорхой байрлалд шинэ утга оноож болно.

```python
red_eggs = [0, 0, 0]
kelly = 1

red_eggs[kelly] = 2
player.place(red_eggs)
```

Энэ код `red_eggs` list-ийн `1` дугаартай байрлалд `2` утга онооно.

---

## 8. Game-based coding жишээ

Доорх код өндөгний тоонуудыг list-д хадгалаад саванд байрлуулж байна.

```python
import player

eggs = []
blue_eggs = 5
red_eggs = 3

eggs.append(blue_eggs)
eggs.append(red_eggs)

player.place(eggs)
```

## 9. Түвшин бүрийн тайлбар

### Level 1: Numeric Lists

Зорилго: Өндгүүдийг цуглуулж, саванд хадгалах боломжтой list үүсгэ.

Гол санаа: Өндөгний тоонуудыг list-д хадгалж саванд байрлуулна.

### Level 2: Combining Lists

Зорилго: Хэд хэдэн барааг list-д хийж, нийлүүлэн шинэ бүтээгдэхүүн гарга.

Гол санаа: Шингэн ба ногооны list-ийг нийлүүлж шинэ бүтээгдэхүүн үүсгэнэ.

### Level 3: String Lists

Зорилго: Хоолоо тавиад гахайчуудын нэрсийг list-д оруулан тэднийг дууд.

Гол санаа: Гахайнуудын нэрийг текст list-д хадгалж, нэр бүрийг дуудна.

### Level 4: Combining String Lists

Зорилго: Хэд хэдэн жимс, ваар цуглуулж list-д хамт хийн жимсний жүүс болго.

Гол санаа: Жимс, сав, ус зэрэг текст утгуудыг list-ээр нэгтгэнэ.

### Level 5: Referencing List Items

Зорилго: Өндөгний сагс авч, өндөг бүрийн тоог шалгаад зөв саванд байрлуул.

Гол санаа: List-ийн index ашиглан зөв саванд зөв өндөг байрлуулна.

### Level 6: Assigning List Values

Зорилго: Ямар тахиа ямар өнгийн хэдэн өндөг гаргасныг list-д утга оноож хадгал.

Гол санаа: List-ийн тодорхой index дээр шинэ утга онооно.
