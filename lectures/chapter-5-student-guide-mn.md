# Бүлэг 5: Жагсаалт үүсгэх

Энэ бүлэгт олон утгыг нэг нэрийн дор хадгалах жагсаалт буюу list ашиглаж сурна.

## Энэ бүлгээр юу сурах вэ?

- Хоосон жагсаалт үүсгэх
- `append()` ашиглан жагсаалтад утга нэмэх
- Тоон болон текст жагсаалт үүсгэх
- Жагсаалтуудыг нийлүүлэх
- Жагсаалтын индекс ашиглан тодорхой утга авах
- Жагсаалтын тодорхой байрлалын утгыг өөрчлөх

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| List | Олон утгыг дарааллаар нь хадгалдаг бүтэц. | eggs = [] |
| append() | Жагсаалтын төгсгөлд шинэ утга нэмнэ. | eggs.append(blue_eggs) |
| Index | Жагсаалтын байрлал. Python-д 0-оос эхэлдэг. | basket[0] |
| List combining | Хоёр жагсаалтыг `+` ашиглан нийлүүлнэ. | mixture = liquids + vegetables |
| Assignment | Жагсаалтын тодорхой байрлалд утга онооно. | red_eggs[kelly] = 2 |

## Ашиглах команд ба жишээнүүд

| Код | Юу хийдэг вэ? |
| --- | --- |
| eggs = [] | Хоосон жагсаалт үүсгэнэ. |
| eggs.append(blue_eggs) | Жагсаалтад утга нэмнэ. |
| mixture = liquids + vegetables | Хоёр жагсаалтыг нийлүүлнэ. |
| player.place(eggs) | Жагсаалтыг байрлуулна. |
| basket[0] | Жагсаалтын эхний утгыг авна. |

## Жишээ код

```python
eggs = []
blue_eggs = 5
eggs.append(blue_eggs)
names = ["Peggle", "Peter", "Piper", "Pedro"]
player.speak("Come here %s" % name)
red_eggs[kelly] = 2
```

## Түвшин бүрийн тайлбар

### Level 1: Numeric Lists

Зорилго: Өндгүүдийг цуглуулж, саванд хадгалах боломжтой жагсаалт үүсгэ.

Гол санаа: Өндөгний тоонуудыг жагсаалтад хадгалж саванд байрлуулна.

### Level 2: Combining Lists

Зорилго: Хэд хэдэн барааг жагсаалтад хийж, нийлүүлэн шинэ бүтээгдэхүүн гарга.

Гол санаа: Шингэн ба ногооны жагсаалтыг нийлүүлж шинэ бүтээгдэхүүн үүсгэнэ.

### Level 3: String Lists

Зорилго: Хоолоо тавиад гахайчуудын нэрсийг жагсаалтад оруулан тэднийг дууд.

Гол санаа: Гахайнуудын нэрийг текст жагсаалтад хадгалж, нэр бүрийг дуудна.

### Level 4: Combining String Lists

Зорилго: Хэд хэдэн жимс, ваар цуглуулж жагсаалтад хамт хийн жимсний жүүс болго.

Гол санаа: Жимс, сав, ус зэрэг текст утгуудыг жагсаалтаар нэгтгэнэ.

### Level 5: Referencing List Items

Зорилго: Өндөгний сагс ав, доторх өндөг бүрийн тоог шалгаад, жагсаалтын байрлалыг ашиглан зөв саванд нь байрлуул.

Гол санаа: Жагсаалтын байрлалыг ашиглан зөв саванд зөв өндөг байрлуулна.

### Level 6: Assigning List Values

Зорилго: Жагсаалтад утга оноох замаар ямар тахиа ямар өнгийн хэдэн өндөг гаргаж дарснийг тодорхойл.

Гол санаа: Жагсаалтын тодорхой индекс дээр шинэ утга оноож, аль тахиа ямар өндөг гаргасныг хадгална.

## Нийтлэг алдаа

| Алдаа | Яагаад буруу вэ? | Зөв хэлбэр |
| --- | --- | --- |
| eggs.append[blue_eggs] | `append` функц тул `()` хэрэгтэй. | eggs.append(blue_eggs) |
| basket[1] эхний утга | Python индекс 0-оос эхэлдэг. | basket[0] |
| names = Peggle, Peter | Жагсаалт ба текст хашилт дутуу. | names = ["Peggle", "Peter"] |
| mixture = [liquids + vegetables] | Илүү nested list үүсгэж болзошгүй. | mixture = liquids + vegetables |

## Алдаа гарвал шалгах зүйлс

1. Команд, хувьсагч, функцийн нэр зөв бичигдсэн үү?
2. `()` хаалт, `:` тэмдэг, `[]` эсвэл `{}` зөв ашиглагдсан уу?
3. Текст утга хашилтын дотор байна уу?
4. Indentation буюу мөрийн зай зөв байна уу?
5. Кодын дараалал газрын зураг дээрх үйлдэлтэй таарч байна уу?
6. `Run` дарсны дараа аль мөрөөс буруу үр дүн гарч байгааг ажигласан уу?

## Дасгал

1. `numbers = []` үүсгээд 3 тоо `append()` ашиглан нэм.
2. `names = ["A", "B", "C"]` жагсаалтын эхний утгыг хэлүүл.
3. Хоёр жагсаалт үүсгээд `+` ашиглан нийлүүл.
4. `basket[0]` ба `basket[1]` ямар ялгаатайг тайлбарла.

## Өөрийгөө шалгах асуултууд

1. Жагсаалт ямар үед хэрэгтэй вэ?
2. `append()` юу хийдэг вэ?
3. Python жагсаалтын эхний индекс хэд вэ?
4. Хоёр жагсаалтыг яаж нийлүүлэх вэ?
5. `red_eggs[kelly] = 2` мөр ямар утга оноож байна вэ?

## Санах гол санаа

Жагсаалт нь олон холбоотой утгыг нэг нэрээр хадгалж, индексээр нь хандах боломж өгдөг.
