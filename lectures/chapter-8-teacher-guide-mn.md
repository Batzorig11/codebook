Эх сурвалж: `src/data/chapters/chapter-8.ts` доторх Chapter 8-ийн сургалтын агуулга.

## Материалын хэрэглээ

- Зориулалт: багшийн лекц, ангийн дадлага, богино үнэлгээ
- Сэдэв: dictionary, key, value, `del`, `items()`, dictionary-тэй функц
- Нийт хугацаа: ойролцоогоор 90 минут
- Хэрэглэх хэлбэр: эхлээд багш үндсэн ойлголтыг тайлбарлаж, дараа нь сурагчид Level 1-Level 6 даалгаврыг платформ дээр гүйцэтгэнэ.

## Хичээлийн зорилго

Энэ бүлгээр сурагчид мэдээллийг түлхүүр-утга хосоор хадгалах dictionary бүтэц ашиглаж, түүний утгыг давталт, функц, объект байрлуулах үйлдэлтэй холбож сурна.

## Суралцах үр дүн

Хичээлийн дараа сурагч дараах чадвартай болсон байна:

- Хоосон dictionary үүсгэх
- Түлхүүр ашиглан утга хадгалах ба авах
- Dictionary ба list-ийн ялгааг тайлбарлах
- `del` ашиглан түлхүүр устгах
- `items()` ашиглан түлхүүр ба утгаар давтах
- Dictionary-г функц болон тоглоомын командтай ашиглах

## Урьдчилсан шаардлага

- Компьютер ашиглах суурь чадвар
- Keyboard ашиглан текст бичих чадвар
- Codingforkids платформын Code Editor хэсэгт нэвтрэх боломж
- Өмнөх бүлгүүдийн үндсэн команд, дарааллын ойлголтыг давтсан байх

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| Dictionary | Түлхүүр-утга хосоор хадгалдаг бүтэц | `bag = {}` |
| Key | Утгыг олох нэр | `bag["Apples"]` |
| Value | Түлхүүрт хадгалсан мэдээлэл | `bag["Apples"] = 5` |
| del | Түлхүүрийг устгах | `del crate["Pipes"]` |
| items() | Түлхүүр ба утгыг хамт давтах | `for name, number in materials.items():` |

## Ашиглах командууд

```python
bag = {}
bag["Apples"] = 5
player.speak(bag)
del crate["Pipes"]
for name, number in materials.items():
player.place(materials["branches"])
```

## Багшийн тайлбар

### 1. Үндсэн санаа

Dictionary-г утасны дэвтэртэй зүйрлэж тайлбарла: нэрээр нь утгыг олно.

### 2. Самбарын тайлбар

List нь байрлалаар, dictionary нь түлхүүрээр ханддаг ялгааг тодруул.

### 3. Ангийн чиглүүлэг

Түлхүүр текст бол хашилт хэрэгтэйг давт.

Сурагчдаас кодоо ажиллуулахын өмнө төлөвлөгөө хэлүүлэх, ажиллуулсны дараа үр дүнг кодын мөртэй холбож тайлбарлуулах дадлыг тогтмол хэрэглэнэ.

## Сурагчийн бие даалтын даалгавар

1. `bag = {}` үүсгээд гурван жимсний тоо хадгал.
2. `bag["Apples"]` утгыг унших жишээ бич.
3. `for name, number in bag.items():` давталт юу хийхийг тайлбарла.
4. Өнөөдрийн хамгийн их алдсан нэг алдаагаа бичээд, зассан аргаа тайлбарла.

## Нийтлэг алдаа ба засах арга

| Алдаа | Шалтгаан | Засах арга |
| --- | --- | --- |
| `bag = []` | Энэ нь list | `bag = {}` |
| `bag[Apples] = 5` | Текст түлхүүр хашилтгүй | `bag["Apples"] = 5` |
| `bag("Apples")` | Dictionary-д дөрвөлжин хаалт ашиглана | `bag["Apples"]` |
| `for name in materials.items():` | Түлхүүр ба утга хоёрыг авахгүй байна | `for name, number in materials.items():` |

5. `items()` ямар үед хэрэгтэй вэ?

## Хариултын түлхүүр

1. Түлхүүр-утга хосоор мэдээлэл хадгалдаг бүтэц.
2. Key нь утгыг олох нэр, value нь хадгалсан мэдээлэл.
3. `Apples` түлхүүрт 5 гэсэн утга хадгална.
4. Dictionary-ээс түлхүүр болон түүний утгыг устгана.
5. Dictionary-ийн бүх түлхүүр, утгыг давталтаар авах үед хэрэгтэй.
