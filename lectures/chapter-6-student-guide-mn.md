# Бүлэг 6: Нөхцөл

## Хичээлийн сэдэв
**if нөхцөл ашиглан кодыг хэрхэн шийдвэр гаргадаг болгох вэ?**

## Зорилго
Энэ хичээлийн дараа сурагчид:

- `if` нөхцөл бичнэ
- `==` болон `!=` харьцуулалтын оператор ашиглана
- List дотор утга байгаа эсэх, урт нь хангалттай эсэхийг шалгана
- Давталт дотор нөхцөл ашиглана
- `break` болон `continue`-ийн санааг ойлгоно
- Нөхцөлөөр өөр өөр зүйл цуглуулах, байрлуулах, нэгтгэх дадлага хийнэ

---

## 1. Нөхцөл гэж юу вэ?

**Нөхцөл** гэдэг нь код тодорхой асуулт шалгаад, үнэн үед нь үйлдэл хийх бүтэц юм.

Жишээ:

```python
if x == 1:
    player.speak("x is 1")
```

Энэ код `x` нь `1`-тэй тэнцүү үед л доторх командыг ажиллуулна.

---

## 2. if statement бичих бүтэц

`if` нөхцөлийн үндсэн бүтэц:

```python
if condition:
    # нөхцөл үнэн үед ажиллах код
```

Анхаарах зүйлс:

- `if` түлхүүр үгээр эхэлнэ
- Нөхцөлийн дараа `:` тавина
- Доторх код indentation-тэй байна
- Нөхцөл худал бол доторх код ажиллахгүй

---

## 3. == болон != оператор

`==` нь хоёр утга тэнцүү эсэхийг шалгана.

```python
if basket[0] == basket[1]:
    player.speak("Same")
```

`!=` нь хоёр утга ялгаатай эсэхийг шалгана.

```python
if basket[0] != basket[1]:
    player.speak("Different")
```

Анхаарах зүйл:

- `=` нь утга онооно
- `==` нь утга харьцуулна

---

## 4. len() ашиглан урт шалгах

`len()` function нь list-ийн уртыг буцаана.

```python
items = ["water", "pumpkin"]

if len(items) < 5:
    player.collect("water")
```

Энэ код `items` list-ийн урт 5-аас бага үед ус цуглуулна.

---

## 5. Давталт дотор нөхцөл ашиглах

Нөхцөлийг давталтын дотор байрлуулж болно.

```python
for x in range(3):
    if x == 0:
        player.place(bag)
    player.move_forward()
```

Энэ үед давталтын тодорхой алхам дээр тусгай үйлдэл хийж байна.

---

## 6. break ба continue

`break` нь давталтыг бүрэн зогсооно.

`continue` нь тухайн алхмыг алгасаад дараагийн давталт руу шилжинэ.

```python
for x in range(5):
    if x == 3:
        break
    player.move_forward()
```

Энэ код `x == 3` болох үед давталтыг зогсооно.

---

## 7. Game-based coding жишээ

Доорх код хоёр өндөг өөр эсэхийг шалгаад үр дүнг хэлүүлж байна.

```python
import player

basket = ["blue egg", "red egg"]

if basket[0] != basket[1]:
    player.speak("Different eggs")
```

---

## 8. Түвшин бүрийн тайлбар

### Level 1: Basic If Statement

Зорилго: Талбай дээрх бүх өндгийг цуглуулж, `if` нөхцөл ашиглан бие биетэй нь харьцуул.

Гол санаа: Өндөгнүүдийг харьцуулж нөхцөл үнэн эсвэл худал эсэхийг шалгана.

### Level 2: Complex If Statement

Зорилго: Талбай дээрх зүйлсийг цуглуулж, нөхцөлийн операторуудыг ашиглан нэгтгэ.

Гол санаа: Олон зүйл цуглуулж, нөхцөл ашиглан ямар үйлдэл хийхээ шийднэ.

### Level 3: Checking for Existence

Зорилго: Савнууд дотор хадгалагдсан орцуудыг хайж олоод, хамтад нь нэгтгэж хоол хий.

Гол санаа: List-ийн урт хангалттай эсэхийг `len()` ашиглан шалгана.

### Level 4: Break and Continue Statements

Зорилго: Барилгуудын хоорондох зам дээр ургасан зэрлэг ургамлуудыг давталтын нөхцөл ашиглан цэвэрлэ.

Гол санаа: Давталтын явцад `break` болон `continue` ашиглах нөхцөлийг ойлгоно.

### Level 5: Loop Conditions

Зорилго: Замд ургасан бүх зэрлэг ургамлыг давталтын нөхцөл ашиглан 12-оос илүүгүй мөр кодоор цуглуулж хог руу хая.

Гол санаа: Давталтын index-ээр өөр өөр үед өөр хэмжээтэй зүйл байрлуулна.

### Level 6: Alternate Loop Conditions

Зорилго: Хашаан дахь бүх жимсийг давталт ашиглан цуглуулж, нэгтгэн jam хий.

Гол санаа: Жимснүүдийг нөхцөлтэй давталтаар цуглуулж, list-д нэмээд нэгтгэнэ.

## 9. Дасгал 1

`if x == 0:` нөхцөл бичээд дотор нь нэг command байрлуул.

### Жишээ хариу

```python
x = 0
if x == 0:
    player.speak("Start")
```

---

## 10. Дасгал 2

Хоёр утга ялгаатай эсэхийг `!=` ашиглан шалга.

### Жишээ хариу

```python
first = "apple"
second = "pear"

if first != second:
    player.speak("Different")
```

---

## 11. Дасгал 3

`items = []` list-ийн уртыг `len(items)` ашиглан хэлүүл.

### Жишээ хариу

```python
items = []
player.speak(len(items))
```

---

## 12. Дасгал 4

Давталт дотор `if x == 1:` нөхцөл нэмээд өөр эргэлт хийлгэ.

### Жишээ хариу

```python
for x in range(3):
    if x == 1:
        player.turn_left()
    player.move_forward()
```
