# Бүлэг 6: Нөхцөл

Энэ бүлэгт код тодорхой нөхцөлөөс хамаарч өөр өөр үйлдэл хийхийг `if` ашиглан сурна.

## Энэ бүлгээр юу сурах вэ?

- `if` нөхцөл бичих
- `==` болон `!=` харьцуулалтын оператор ашиглах
- Жагсаалт дотор утга байгаа эсэх, урт нь хангалттай эсэхийг шалгах
- Давталт дотор нөхцөл ашиглах
- `break` болон `continue`-ийн санааг ойлгох
- Нөхцөлөөр өөр өөр зүйл цуглуулах, байрлуулах, нэгтгэх

## Гол ойлголтууд

| Ойлголт | Тайлбар | Жишээ |
| --- | --- | --- |
| If statement | Нөхцөл үнэн үед л доторх код ажиллана. | if basket[0] == basket[1]: |
| == | Хоёр утга тэнцүү эсэхийг шалгана. | x == 1 |
| != | Хоёр утга ялгаатай эсэхийг шалгана. | x != 1 |
| len() | Жагсаалтын уртыг олно. | len(items) |
| Loop condition | Давталтын алхам бүр дээр нөхцөл шалгана. | if x == 0: |

## Ашиглах команд ба жишээнүүд

| Код | Юу хийдэг вэ? |
| --- | --- |
| if basket[0] == basket[1]: | Хоёр утга тэнцүү эсэхийг шалгана. |
| if basket[1] != basket[2]: | Хоёр утга ялгаатай эсэхийг шалгана. |
| if len(items) < 5: | Жагсаалтын урт 5-аас бага эсэхийг шалгана. |
| for x in range(3): | Давталт дотор нөхцөл шалгах боломж өгнө. |
| if x == 0: | Давталтын тодорхой алхамд тусгай үйлдэл хийнэ. |

## Жишээ код

```python
basket = ["blue egg", "red egg"]
if basket[0] != basket[1]:
    player.speak("Different eggs")
if len(items) < 5:
    player.collect("water")
for x in range(3):
    if x == 0:
        player.place(bag)
```

## Түвшин бүрийн тайлбар

### Level 1: Basic If Statement

Зорилго: Талбай дээрх бүх өндгийг цуглуулж, if илэрхийллийн нөхцөлийг ашиглан бие биетэй нь харьцуул.

Гол санаа: Өндөгнүүдийг харьцуулж нөхцөл үнэн эсвэл худал эсэхийг шалгана.

### Level 2: Complex If Statement

Зорилго: Талбай дээрх зүйлсийг цуглуулж, нөхцөлийн операторуудыг ашиглан нэгтгэ.

Гол санаа: Олон зүйл цуглуулж, нөхцөл ашиглан ямар үйлдэл хийхээ шийднэ.

### Level 3: Checking for Existence

Зорилго: Савнууд дотор хадгалагдсан орцуудыг хайж олоод, хамтад нь нэгтгэж хоол хийж түвшнийг дуусга.

Гол санаа: Жагсаалтын урт хангалттай эсэхийг `len()` ашиглан шалгана.

### Level 4: Break and Continue Statements

Зорилго: Барилгуудын хоорондох зам дээр ургасан зэрлэг ургамлуудыг давталтын нөхцлүүдийг ашиглан цэвэрлэ.

Гол санаа: Давталтын явцад `break` болон `continue` ашиглах нөхцөлийг ойлгоно.

### Level 5: Loop Conditions

Зорилго: Замд ургасан бүх зэрлэг ургамлыг давталтын нөхцөл ашиглан 12-оос илүүгүй мөр кодоор цуглуулж хог руу хая.

Гол санаа: Давталтын индексээр өөр өөр үед өөр хэмжээтэй зүйл байрлуулна.

### Level 6: Alternate Loop Conditions

Зорилго: Хашаан дахь бүх жимсийг давталт ашиглан цуглуулж, нэгтгэн Jam хий.

Гол санаа: Жимснүүдийг нөхцөлтэй давталтаар цуглуулж, жагсаалтад нэмээд нэгтгэнэ.

## Нийтлэг алдаа

| Алдаа | Яагаад буруу вэ? | Зөв хэлбэр |
| --- | --- | --- |
| if x = 1: | `=` нь оноолт, харьцуулалт биш. | if x == 1: |
| if x == 1 | `:` тэмдэг дутуу. | if x == 1: |
| if basket[0] = basket[1]: | Харьцуулахдаа `==` ашиглана. | if basket[0] == basket[1]: |
| len[items] | `len` функц тул `()` хэрэгтэй. | len(items) |

## Алдаа гарвал шалгах зүйлс

1. Команд, хувьсагч, функцийн нэр зөв бичигдсэн үү?
2. `()` хаалт, `:` тэмдэг, `[]` эсвэл `{}` зөв ашиглагдсан уу?
3. Текст утга хашилтын дотор байна уу?
4. Indentation буюу мөрийн зай зөв байна уу?
5. Кодын дараалал газрын зураг дээрх үйлдэлтэй таарч байна уу?
6. `Run` дарсны дараа аль мөрөөс буруу үр дүн гарч байгааг ажигласан уу?

## Дасгал

1. `if x == 0:` нөхцөл бичээд дотор нь нэг команд байрлуул.
2. Хоёр утга ялгаатай эсэхийг `!=` ашиглан шалга.
3. `items = []` жагсаалтын уртыг `len(items)` ашиглан хэлүүл.
4. Давталт дотор `if x == 1:` нөхцөл нэмээд өөр эргэлт хийлгэ.

## Өөрийгөө шалгах асуултууд

1. `if` ямар үед ажилладаг вэ?
2. `=` ба `==` хоёрын ялгаа юу вэ?
3. `!=` юу шалгадаг вэ?
4. `len(items)` ямар утга буцаадаг вэ?
5. Давталт дотор нөхцөл ашиглах нь ямар давуу талтай вэ?

## Санах гол санаа

Нөхцөл нь кодыг илүү ухаалаг болгож, зөвхөн хэрэгтэй үед тодорхой үйлдэл ажиллуулдаг.
