# Бүлэг 6: Нөхцөл

> **Энэ хичээлээр:**
> Код тодорхой нөхцөлөөс хамаарч өөр өөр үйлдэл хийхийг `if` ашиглан сурна.

---

# Алхам 1: If нөхцөл (Хэрэв... бол)

`if` нөхцөл нь кодыг илүү ухаалаг болгож, зөвхөн хэрэгтэй үед тодорхой үйлдэл ажиллуулдаг.

```python
x = 5

if x == 5:
    player.speak("x is 5")
```

**Яаж ажилладаг вэ?**

1. `x == 5` — нөхцөл шалгана (5 == 5 = үнэн)
2. Нөхцөл үнэн тул доторх код ажиллана
3. `player.speak("x is 5")` — дэлгэц дээр "x is 5" гэж харуулна

| Оператор | Үйлдэл | Жишээ |
| --- | --- | --- |
| `==` | Тэнцүү эсэх | `x == 5` |
| `!=` | Ялгаатай эсэх | `x != 5` |
| `<` | Бага эсэх | `x < 10` |
| `>` | Их эсэх | `x > 3` |

---

# Алхам 2: Харьцуулалтын оператор (== vs =)

**`=` болон `==` хоёрын ялгаа:**

| Оператор | Нэр | Жишээ | Утга |
| --- | --- | --- | --- |
| `=` | Оноолт | `x = 5` | x-д 5 утга онооно |
| `==` | Харьцуулалт | `x == 5` | x утга 5-тэй тэнцүү эсэхийг шалгана |

**Жишээ:**

```python
# Оноолт
x = 5

# Харьцуулалт
if x == 5:
    player.speak("Yes!")
```

**Буруу жишээ:**

```python
if x = 5:  # ❌ Алдаа! Оноолт биш харьцуулалт хэрэгтэй
    player.speak("Yes!")
```

> **Анхаарах:**
> Нөхцөлд `=` биш `==` ашиглана. `=` нь оноолт, `==` нь харьцуулалт.

---

# Алхам 3: Жагсаалт шалгах (len)

Жагсаалтын урт болон утгыг шалгах.

```python
items = ["apple", "banana"]

if len(items) < 5:
    player.speak("Not enough items")
```

**`len()` функц:**

| Код | Гаралт |
| --- | --- |
| `len([1, 2, 3])` | 3 |
| `len([])` | 0 |
| `len(["a", "b"])` | 2 |

**Жагсаалтын утга байгаа эсэхийг шалгах:**

```python
if basket[0] != basket[1]:
    player.speak("Different eggs")
```

> **Анхаарах:**
> `len[items]` гэж бичвэл алдаа гарна. `len` нь функц тул `()` хэрэгтэй.

# Алхам 4: Давталт дотор нөхцөл

Давталтын явцад нөхцөл шалгах.

```python
for x in range(3):
    if x == 0:
        player.place(bag)
    else:
        player.move_forward()
```

**Яаж ажилладаг вэ?**

| Давталт | x утга | Нөхцөл | Үйлдэл |
| --- | --- | --- | --- |
| 1 | 0 | x == 0 (үнэн) | `player.place(bag)` |
| 2 | 1 | x == 0 (худал) | `player.move_forward()` |
| 3 | 2 | x == 0 (худал) | `player.move_forward()` |

**Break болон Continue:**

```python
for x in range(10):
    if x == 5:
        break  # Давталтыг зогсооно
    player.move_forward()
```

# Алхам 5: Тоглоомын түвшинд хэрэглэх

**Level 1: Basic If Statement**

Өндөгнүүдийг харьцуулж нөхцөл үнэн эсвэл худал эсэхийг шалгана.

```python
basket = ["blue egg", "red egg"]
if basket[0] == basket[1]:
    player.speak("Same eggs")
```

**Level 2-3: Complex Conditions**

Олон зүйл цуглуулж, нөхцөл ашиглан ямар үйлдэл хийхээ шийднэ.

```python
if len(items) < 5:
    player.collect("water")
else:
    player.place(items)
```

**Level 4-6: Loop Conditions**

Давталтын индексээр өөр өөр үед өөр хэмжээтэй зүйл байрлуулна.

```python
for x in range(3):
    if x == 0:
        player.place(bag)
    player.move_forward()
```

**Нийтлэг алдаа (Анхаарах зүйлс):**

| Алдаа | Яагаад буруу вэ? | Зөв хэлбэр |
| --- | --- | --- |
| `if x = 1:` | `=` нь оноолт, харьцуулалт биш. | `if x == 1:` |
| `if x == 1` | `:` тэмдэг дутуу. | `if x == 1:` |
| `if basket[0] = basket[1]:` | Харьцуулахдаа `==` ашиглана. | `if basket[0] == basket[1]:` |
| `len[items]` | `len` функц тул `()` хэрэгтэй. | `len(items)` |

# Quiz: Өөрийгөө шалгаарай

## Асуулт 1
`if` ямар үед ажилладаг вэ?

- А) Үргэлж
- Б) Нөхцөл үнэн үед
- В) Нөхцөл худал үед
- Г) Хэзээ ч ажиллахгүй

**Зөв хариулт:** Б
**Тайлбар:** `if` нөхцөл нь зөвхөн нөхцөл үнэн байх үед л доторх кодыг ажиллуулдаг.

## Асуулт 2
`=` ба `==` хоёрын ялгаа юу вэ?

- А) Ялгаагүй
- Б) `=` = оноолт, `==` = харьцуулалт
- В) `=` = харьцуулалт, `==` = оноолт
- Г) `==` = нэмэх

**Зөв хариулт:** Б
**Тайлбар:** `=` нь утга оноодог, `==` нь хоёр утгыг харьцуулдаг.

## Асуулт 3
`!=` юу шалгадаг вэ?

- А) Тэнцүү эсэх
- Б) Ялгаатай эсэх
- В) Их эсэх
- Г) Бага эсэх

**Зөв хариулт:** Б
**Тайлбар:** `!=` нь "тэнцүү биш" гэсэн утгатай. Хоёр утга ялгаатай эсэхийг шалгана.

## Асуулт 4
`len(items)` ямар утга буцаадаг вэ?

- А) Эхний утгыг
- Б) Жагсаалтын уртыг
- В) Сүүлийн утгыг
- Г) Хоосон утга

**Зөв хариулт:** Б
**Тайлбар:** `len()` функц жагсаалт эсвэл текстийн уртыг (элементийн тоог) буцаадаг.

## Асуулт 5
Давталт дотор нөхцөл ашиглах нь ямар давуу талтай вэ?

- А) Код удаан ажиллана
- Б) Тодорхой үед өөр үйлдэл хийж болно
- В) Алдаа илүү гарна
- Г) Код илүү урт болно

**Зөв хариулт:** Б
**Тайлбар:** Давталтын тодорхой алхам дээр өөр үйлдэл хийх боломж олгодог.

## Асуулт 6
Дараах код ямар үр дүн гаргах вэ?

```python
x = 3
if x == 3:
    player.speak("Yes")
else:
    player.speak("No")
```

- А) No
- Б) Yes
- В) Алдаа гарна
- Г) Юу ч хэвлэхгүй

**Зөв хариулт:** Б
**Тайлбар:** x утга 3 тул `x == 3` нөхцөл үнэн. "Yes" гэж хэвлэнэ.

# Дүгнэлт

Энэ бүлэгт чи:

1. `if` нөхцөлийг сурлаа
2. `==` болон `!=` операторуудыг сурлаа
3. `len()` функцийг сурлаа
4. Давталт дотор нөхцөл ашиглахыг сурлаа
5. Нөхцөлөөр өөр өөр үйлдэл хийхийг сурлаа
6. `break` болон `continue`-ийн санааг ойлголоо

Нөхцөл нь кодыг илүү ухаалаг болгож, зөвхөн хэрэгтэй үед тодорхой үйлдэл ажиллуулдаг.

---

# Гол санаа

- `if` = нөхцөл үнэн үед код ажиллуулна
- `==` = тэнцүү эсэхийг шалгана
- `!=` = ялгаатай эсэхийг шалгана
- `len()` = жагсаалтын уртыг олно
- Нөхцөлд `==` ашиглана (`=` биш)
- Давталт дотор нөхцөл ашиглаж болно
