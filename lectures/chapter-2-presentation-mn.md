# Бүлэг 2

## Хувьсагч ба өгөгдлийн төрөл

VARIABLES AND TYPES

---

# Энэ хичээлээр юу сурах вэ?

- Хувьсагч гэж юу болохыг тайлбарлах
- Тоон болон текст утгыг хувьсагчид хадгалах
- Тайлбар буюу comment ашиглан кодын мөрийг ажиллуулахгүй болгох
- `collect()`, `water()`, `open()`, `close()`, `place()` командуудыг хэрэглэх
- Хувьсагчийг функцийн аргумент болгон ашиглах

---

# Гол ойлголтууд

| Ойлголт | Тайлбар |
| --- | --- |
| Хувьсагч | Утгад өгсөн нэр. Дараа нь тэр нэрээрээ ашиглаж болно. |
| Тоон утга | Тоо хадгалсан хувьсагч. |
| Текст утга | Хашилтын дотор бичсэн үг эсвэл өгүүлбэр. |
| Comment | Кодод тайлбар үлдээх эсвэл мөрийг ажиллуулахгүй болгох арга. |
| Аргумент | Функцэд дамжуулж буй утга. |

---

# Жишээ код

```python
planks = 4
bricks = 3
wheat = 5
bag1 = "Pumpkin"
player.place(bag1)
```

---

# Ашиглах командууд

| Код | Үйлдэл |
| --- | --- |
| `player.water()` | Тэвш эсвэл ургацыг усална. |
| `player.collect("water")` | Худгаас ус цуглуулна. |
| `player.open()` | Хаалга, авдар зэрэг объектыг нээнэ. |
| `player.close()` | Нээсэн объектыг хаана. |
| `player.place(wheat)` | Хувьсагчид хадгалсан зүйлийг байрлуулна. |

---

# Level 1: Watering objects

Зорилго:

Усны савыг авч 3 тэвшийг усаар дүүргэж түвшнийг дуусга.

Гол санаа:

Усны сав авч тэвш бүрийн өмнө зөв чиглэл рүү хараад усална.

---

# Level 2: Commenting code

Зорилго:

Код засварлагч дээрх тайлбаруудыг өөрчилж гарц руу хүр!

Гол санаа:

Comment нь кодын мөрийг түр идэвхгүй болгож чадна. Аль мөр ажиллах ёстойг ялгаж сур.

---

# Level 3: Collecting resources

Зорилго:

Худгаас ус аваад саваа дүүргээд 5 ургацыг бүгдийг нь усалж түвшнийг дуусга!

Гол санаа:

Эхлээд усаа цуглуулж, дараа нь X тэмдэг бүр дээр очиж ургацаа усална.

---

# Level 4: Opening and closing commands

Зорилго:

Хашааг нээж талбай руу ороод жүчээний 4 үүдийг бүгдийг нь хаагаад түвшнийг дуусга!

Гол санаа:

Орохдоо `open()`, ажлаа дуусгаад `close()` ашиглана.

---

# Level 5: Number variables

Зорилго:

Банз (planks), тоосго (bricks) цуглуулаад хувьсагчид хадгалж түвшнийг дуусга!

Гол санаа:

Цуглуулсан банз, тоосгоны тоог хувьсагчид хадгална.

---

# Level 6: Placing objects

Зорилго:

Талбай дээрх улаан буудайг цуглуулаад хувьсагчид хадгал, авдарт нь байрлуулаад хаагаад түвшнийг дуусга!

Гол санаа:

Цуглуулсан улаан буудайн тоог хувьсагчид хадгалаад `place()` функцэд дамжуулна.

---

# Level 7: String variables

Зорилго:

3 барааг аваад тус тусад нь хувьсагчид хадгал, авдруудыг нээж тус бүрд нь байрлуулаад хаагаад түвшнийг дуусга!

Гол санаа:

Текст утга хашилтын дотор бичигддэг. Жишээ нь `bag1 = "Pumpkin"`.

# Алдаа гарвал шалгах зүйлс

3. Текст хашилттай байна уу?
4. Indentation зөв байна уу?
5. Кодын дараалал газрын зурагтай таарч байна уу?

# Ангийн богино дасгал

1. `logs = 4` гэсэн хувьсагч үүсгээд `player.place(logs)` гэж ашигла.
2. `bag1 = "Pumpkin"` мөрийг `bag2 = "Carrot"` болгож өөрчилж турш.
3. Comment ашиглан нэг хөдөлгөөний мөрийг түр идэвхгүй болго.
4. Нээх, байрлуулах, хаах дарааллыг өөрийн үгээр бич.

# Дүгнэлт

Хувьсагч нь утгыг нэрээр нь хадгалж, дараа нь тэр нэрийг функцэд дамжуулах боломж өгдөг.

Санах дараалал:

1. Газрын зургаа ажигла.
2. Шаардлагатай өгөгдлөө тодорхойл.
3. Командаа зөв дарааллаар бич.
4. `Run` дарж шалга.
5. Алдааг мөр мөрөөр нь зас.
