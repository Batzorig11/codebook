# Бүлэг 5

## Жагсаалт үүсгэх

CREATING LISTS

---

# Энэ хичээлээр юу сурах вэ?

- Хоосон жагсаалт үүсгэх
- `append()` ашиглан жагсаалтад утга нэмэх
- Тоон болон текст жагсаалт үүсгэх
- Жагсаалтуудыг нийлүүлэх
- Жагсаалтын индекс ашиглан тодорхой утга авах

---

# Гол ойлголтууд

| Ойлголт | Тайлбар |
| --- | --- |
| List | Олон утгыг дарааллаар нь хадгалдаг бүтэц. |
| append() | Жагсаалтын төгсгөлд шинэ утга нэмнэ. |
| Index | Жагсаалтын байрлал. Python-д 0-оос эхэлдэг. |
| List combining | Хоёр жагсаалтыг `+` ашиглан нийлүүлнэ. |
| Assignment | Жагсаалтын тодорхой байрлалд утга онооно. |

---

# Жишээ код

```python
eggs = []
blue_eggs = 5
eggs.append(blue_eggs)
names = ["Peggle", "Peter", "Piper", "Pedro"]
player.speak("Come here %s" % name)
red_eggs[kelly] = 2
```

---

# Ашиглах командууд

| Код | Үйлдэл |
| --- | --- |
| `eggs = []` | Хоосон жагсаалт үүсгэнэ. |
| `eggs.append(blue_eggs)` | Жагсаалтад утга нэмнэ. |
| `mixture = liquids + vegetables` | Хоёр жагсаалтыг нийлүүлнэ. |
| `player.place(eggs)` | Жагсаалтыг байрлуулна. |
| `basket[0]` | Жагсаалтын эхний утгыг авна. |

---

# Level 1: Numeric Lists

Зорилго:

Өндгүүдийг цуглуулж, саванд хадгалах боломжтой жагсаалт үүсгэ.

Гол санаа:

Өндөгний тоонуудыг жагсаалтад хадгалж саванд байрлуулна.

---

# Level 2: Combining Lists

Зорилго:

Хэд хэдэн барааг жагсаалтад хийж, нийлүүлэн шинэ бүтээгдэхүүн гарга.

Гол санаа:

Шингэн ба ногооны жагсаалтыг нийлүүлж шинэ бүтээгдэхүүн үүсгэнэ.

---

# Level 3: String Lists

Зорилго:

Хоолоо тавиад гахайчуудын нэрсийг жагсаалтад оруулан тэднийг дууд.

Гол санаа:

Гахайнуудын нэрийг текст жагсаалтад хадгалж, нэр бүрийг дуудна.

---

# Level 4: Combining String Lists

Зорилго:

Хэд хэдэн жимс, ваар цуглуулж жагсаалтад хамт хийн жимсний жүүс болго.

Гол санаа:

Жимс, сав, ус зэрэг текст утгуудыг жагсаалтаар нэгтгэнэ.

---

# Level 5: Referencing List Items

Зорилго:

Өндөгний сагс ав, доторх өндөг бүрийн тоог шалгаад, жагсаалтын байрлалыг ашиглан зөв саванд нь байрлуул.

Гол санаа:

Жагсаалтын байрлалыг ашиглан зөв саванд зөв өндөг байрлуулна.

---

# Level 6: Assigning List Values

Зорилго:

Жагсаалтад утга оноох замаар ямар тахиа ямар өнгийн хэдэн өндөг гаргаж дарснийг тодорхойл.

Гол санаа:

Жагсаалтын тодорхой индекс дээр шинэ утга оноож, аль тахиа ямар өндөг гаргасныг хадгална.

---

# Нийтлэг алдаа

| Буруу | Зөв |
| --- | --- |
| `eggs.append[blue_eggs]` | `eggs.append(blue_eggs)` |
| `basket[1] эхний утга` | `basket[0]` |
| `names = Peggle, Peter` | `names = ["Peggle", "Peter"]` |
| `mixture = [liquids + vegetables]` | `mixture = liquids + vegetables` |

---

# Алдаа гарвал шалгах зүйлс

1. Нэрс зөв бичигдсэн үү?
2. Хаалт, цэг, `:` тэмдэг зөв байна уу?
3. Текст хашилттай байна уу?
4. Indentation зөв байна уу?
5. Кодын дараалал газрын зурагтай таарч байна уу?

---

# Ангийн богино дасгал

1. `numbers = []` үүсгээд 3 тоо `append()` ашиглан нэм.
2. `names = ["A", "B", "C"]` жагсаалтын эхний утгыг хэлүүл.
3. Хоёр жагсаалт үүсгээд `+` ашиглан нийлүүл.
4. `basket[0]` ба `basket[1]` ямар ялгаатайг тайлбарла.

---

# Өөрийгөө шалгах асуултууд

1. Жагсаалт ямар үед хэрэгтэй вэ?
2. `append()` юу хийдэг вэ?
3. Python жагсаалтын эхний индекс хэд вэ?
4. Хоёр жагсаалтыг яаж нийлүүлэх вэ?
5. `red_eggs[kelly] = 2` мөр ямар утга оноож байна вэ?

---

# Дүгнэлт

Жагсаалт нь олон холбоотой утгыг нэг нэрээр хадгалж, индексээр нь хандах боломж өгдөг.

Санах дараалал:

1. Газрын зургаа ажигла.
2. Шаардлагатай өгөгдлөө тодорхойл.
3. Командаа зөв дарааллаар бич.
4. `Run` дарж шалга.
5. Алдааг мөр мөрөөр нь зас.
