# Бүлэг 7

## Өөрийн функц үүсгэх

CREATING YOUR OWN FUNCTIONS

---

# Энэ хичээлээр юу сурах вэ?

- `def` ашиглан өөрийн функц үүсгэх
- Функц дотор давталт, нөхцөл, оператор ашиглах
- Функцэд аргумент дамжуулах
- `return` ашиглан функцээс утга буцаах
- Жагсаалтыг функцэд дамжуулж боловсруулах

---

# Гол ойлголтууд

| Ойлголт | Тайлбар |
| --- | --- |
| Custom function | Өөрийн нэртэй, дахин ашиглаж болох кодын хэсэг. |
| Argument | Функцэд гаднаас дамжуулах утга. |
| Return | Функцээс үр дүн буцаана. |
| Reuse | Нэг удаа тодорхойлоод олон удаа дуудна. |
| Function body | Функцийн дотор indentation-тэй бичигдсэн командууд. |

---

# Жишээ код

```python
def repeat_push():
    player.push()
    player.move_forward()
repeat_push()
def add_numbers(num1, num2, num3):
    return(num1 + num2 + num3)
```

---

# Ашиглах командууд

| Код | Үйлдэл |
| --- | --- |
| `def repeat_push():` | Чулуу түлхэх үйлдлийг функц болгоно. |
| `def water_crops(count):` | Хэдэн удаа услахыг аргументаар авна. |
| `water_crops(4)` | Функцийг 4 гэсэн аргументтай дуудна. |
| `return(num1 + num2 + num3)` | Нийлбэрийг буцаана. |
| `navigate_swamp("build")` | Нөхцөлтэй функц дуудна. |

# Ангийн богино дасгал

1. `def move_twice():` функц үүсгээд хоёр удаа урагшлуул.
2. `def say_word(word):` функц үүсгээд `player.speak(word)` ажиллуул.
3. `def add(a, b):` функцээс нийлбэр буцаа.

# Дүгнэлт

Санах дараалал:

1. Газрын зургаа ажигла.
2. Шаардлагатай өгөгдлөө тодорхойл.
3. Командаа зөв дарааллаар бич.
4. `Run` дарж шалга.
5. Алдааг мөр мөрөөр нь зас.
